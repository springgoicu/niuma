# ADR-0014：牛马比例幼态化——大头、短粗腿、圆躯干

- 状态：已采纳
- 日期：2026-11-02
- 取代：ADR-0010 第 52–54 行的牛马部位数值表；ADR-0010 第 3 条「硬朗卡通画法」中关于眉线与尖角的局部画法

## 背景

64 网格解决了「画不清楚」，但上线后的反馈换成了另一句话：**太生硬**。

拆开看是四件事，全部落在比例与局部画法上，与分辨率无关：

1. **头身比失衡**：头径 18.4 / 站立高 48.6（0.38），马 15.2 / 49.8（0.31）。
   读起来像「板凳上架着一颗方块头」；
2. **腿过长且直**：腿占站立高 0.36 / 0.40，四条腿等宽直柱，侧视里几乎并成两根；
3. **躯干是低圆角方块**（牛 bodyR 3.5），正面肩线是一条 2.4px 厚的横杠，把肩切成直角；
4. **脸上压着一道眉线**（`drawEye` 里的 `rect(x-1, y-2, w+2, 1)`），在浅色牛脸上读成皱眉；
   吻部又大又居中，进一步把脸拉长。

## 问题

这四条不是「细节不够」，而是同一类错误：**把成年四足动物的比例直接搬进 64 格**。

可爱（幼态）的读法来自一组相反的信号：头占身体的比例高、眼睛大且靠脸中、吻短小、
四肢短粗、轮廓圆。只改其中一项就会失衡——只缩腿会变成矮脚板凳，
只放大头会变成头重脚轻的雪人，只加大圆角会变成一颗圆球。

## 备选方案

| 方案 | 收益 | 代价 | 不可逆性 |
|---|---|---|---|
| A. 保持比例，只重画画法 | 最稳，配件零风险 | 头身比不变，萌感上限很低 | 低 |
| B. 温和圆润（只加大圆角、去眉线） | 改动最小 | 腿长与头身比仍是成年比例，「生硬」只解决一半 | 低 |
| C. 幼态萌（采纳） | 头身比、腿比、轮廓一起改，剪影直接变「小动物」 | 站立高降 2.4 texel；配件相对缩小约 13% | 中 |
| D. 强烈 Q 版（头占一半） | 最萌 | 与 64 格、四段腿、世界尺度冲突，配件比例彻底失配 | 高 |

选 C。A/B 只改表面，D 会牺牲 ADR-0010 好不容易换来的「四段腿可读」。

## 决策

### 1. 比例参数（`ANATOMY` 仍是唯一来源）

| 部位 | 牛（旧 → 新） | 马（旧 → 新） |
|---|---|---|
| headR | 9.2 → 10.4 | 7.6 → 9.0 |
| legH / legW | 17.5 / 4.2 → 16 / 4.8 | 20 / 3.6 → 17.6 / 4.2 |
| bodyW / bodyH / bodyR | 23 / 15.2 / 3.5 → 24.4 / 16 / 6.2 | 19 / 13.2 / 6.5 → 19.8 / 14 / 7.0 |
| neckH / neckW | 8.2 / 5.2 → 5.4 / 6.0 | 10.5 / 4.2 → 7.6 / 5.2 |
| muzzleRx / muzzleRy | 5 / 3.4 → 4.2 / 3.0 | 3.4 / 3.2 → 3.2 / 3.0 |
| earW / earH | 4.5 / 3 → 5.2 / 3.6 | 2 / 4 → 2.6 / 3.6 |
| hoofH | 4 → 4.2 | 4 → 4.2 |

`standHeightOf` 的公式未动。派生量：

- 站立总高：牛 48.55 → 46.18，马 49.84 → 46.66（差 0.48，仍 ≤2）；
- 头径 / 站立高：0.38 / 0.31 → **0.45 / 0.386**；
- 腿长 / 站立高：0.36 / 0.40 → **0.347 / 0.377**。

### 2. 面部

- `drawEye` 删掉眉线，改为 **5×5 眼珠 + 上眼睑 1px（`EyeShade`）+ 2×2 高光**；
  不再加左右眼睑——5px 的眼珠两侧各加 1px 会撑成 7px 深色方框，读成墨镜；
- 闭眼线宽度跟眼珠走（5px），眨眼帧只保留一种眼睛造型；
- 吻部纵向下移到 `headR * 0.52`（旧 0.42），`muzzleRx` 收窄约 16%，鼻孔缩到 1.5×1.2；
- 牛角 `reach` 4/6 → 3.2/4.6、二段端宽 1.8 → 3.4，并在角尖补半圆（旧值在放大后是一根针）；
- 马鬃由 4 根长尖改 5 根短脊，正面由 3 根改 5 根（中间最高）；
- 耳朵末端补圆头；马耳根部加粗到 2.6。

### 3. 形体与姿态

- 躯干圆角 6.2 / 7.0；正面肩线从 2.4 厚的横杠收成 1.6 厚、`bodyW - 4` 宽的短带；
- 屈膝量 1.6 → 1.2，正面腿缝 1.8 → 1.2（腿变粗后要收，否则四根柱子撑满躯干）；
- `sit` 落座量 7 → 5.5、低头量 5 → 6；腿短 2px 后沿用旧偏移会让屁股悬空；
- `haunch`（坐姿臀部）由写死 12×8 改为按 `bodyW` 比例缩放；
- `HEAD_CX` 42 → 40.5（头径 +2 后原间距读成长脖子）；
- 颈挂点由 `bodyH * 0.14` 上移到 `0.22` 并前移 1px；尾巴挂点外移 1px。

### 4. 配件

`COSMETIC_SIZE` 仍是 20，配件坐标一行未改；锚点继续由 `landmarksOf()` 推导。
眼睛锚点改为与 `drawEye` 共用新增的 `eyeMetricsOf()` 的中心，避免换眼型时眼镜漂移（ADR-0007）。

代价：帽子相对头宽从约 1.1 降到约 0.96，实测 `.proof/worn.png` 仍咬住头顶、不浮空。

### 5. 契约

- ADR-0010 留下的三条比例断言（总高差 ≤2、总高 46..56、牛宽 > 马宽 +2）一条不放松；
- 新增四条幼态回归线：头占比下限、腿占比上限、眼睛 ≥5×5、眨眼帧眼睛比睁眼帧矮；
- 新增导出 `proportionsOf()` / `eyeSizeOf()`，测试与美术评审读同一份数，不再抄魔数。

## 后果

- 正面：头占上半身、眼睛有高光、肩线不再把肩切成方块；侧面：头贴躯干、颈几乎不可见，
  是幼态的正常形态，不再是「长脖子小头」；
- 牛仍明显宽于马（躯干 24.4 vs 19.8），角 / 鬃 / 吻宽差保留，并排一眼可分；
- 站立高降低 2.4，世界坐标、碰撞半径、相机、地形比例均无需联动；
- 负面：帽子与发型相对小约 13%（本轮接受，未重画）；配件类别基准行仍是 20 的画布，
  将来要做宽檐帽需要整体提到 22；
- 回滚：把 `ANATOMY` 与本 ADR 第 2、3 节的画法改动退回，跑一次 `pnpm assets` 即可；
  新增的四条测试会立刻暴露比例回退。

## 复核信号

- 若再次出现「生硬」反馈，先看头占比是否低于 0.42 / 0.36、腿占比是否超过 0.38，
  不要先调颜色或描边；
- 若配件浮空或压住眼睛，修 `landmarksOf()` 的派生（`eyeMetricsOf` 中心），不手改锚点表；
- 若出现「眼睛像墨镜」，检查是否又给眼珠加了左右眼睑——只保留上眼睑 1px；
- 若头部在 emote 起跳帧顶到画布边，优先降 `hop`，不要压缩头径。

# ADR-0116：互动逻辑全量审查与反馈打磨

- 状态：已采纳
- 日期：2026-11-16
- 关联：ADR-0024（轻互动留客户端）、0051/0065（发泄裁决与入座免伤）、0083（P2P 挑战总线）、
  0085（道具与 Buff）、0087（热区注册表）、0093（入座门禁）、0100（弱交互场所演出）、0112（全园区播报）

## 背景

对四类互动（F 键热区与提示、玩家间互动、场所弱互动、姿态与移动）做一次证据化审查，
先回答「哪里真的有问题」，再按玩家可感知价值排序落地优化。审查由两路独立探索 +
一轮对抗复核（PRIMARY → ADVERSARY → SYNTH）完成，先立约束与非目标：

- 不变量：提示什么按 F 就是什么；门禁不过只提示不发包；弱交互不进协议；失败有回执；热路径零分配。
- 非目标：不推翻既有手感与数值、不改渲染管线 / 地形 / 图集、不把弱交互升级成服务端权威玩法。
- 反向成本：提示与按键漂移会持续制造「按了没反应」；门禁口径不一致会留下可伪造绕过；
  反馈缺失让互动像单机。拖延只会让这些问题随热区数量增长而放大。

## 审查结论（对抗裁决后）

站得住的问题 2 个，记入 backlog 2 个，证伪 2 个：

| 编号 | 问题 | 裁决 |
|---|---|---|
| A | 茶台商店 / 豪宅 / 观战投选三个弹窗没有 capture 吞键，`KeyboardInput` 在 bubble 阶段无条件监听；开面板回调也未清移动掩码，按住方向键时角色在面板背后滑行 | hold（high） |
| B | 快捷打赏不读余额，服务端对扣款失败静默 `return`、协议无 tip reject 包，余额不足时「点了没反应」 | hold（high） |
| E | P2P 应战方在 TTL 到期 / 发起方离线等失败分支收不到回执 | downgrade（窄竞态，本次顺带修） |
| F | `?motion=0` 下压暗层与闪光仍随 `dtMs` 推进，未严格「停在第一帧」 | downgrade（仅调试模式，backlog） |
| C | 八角笼押注用 `seatInGroup` 而非 `seatMatchesHotspot`，被指违背门禁一致性 | drop：`arenaSeat` 热区只有 `seatGroupId`，两函数在长椅场景完全等价；ADR-0093 明确把该廉价早退当参照 |
| D | `actionPresentation.unavailable` 未覆盖「行走中无座」 | drop：`unavailable` 语义本就是「降级显示但仍可点击给提示」，且该状态与 `seatAvailable` 相关，presentation 刻意不接收它 |

其余单元（热区同表同优先级、发泄双端同源、道具钳制与退款、播报分级、日期口径、零分配）
经证据核对为 align，不在本次改动范围。

## 决策

1. **吞键收敛为单一深模块**：新增 `useModalKeys(enabled, onClose)`，把 GAME_KEYS 集合、
   capture 阶段、IME 组合态、焦点交互元素放行、Esc 关闭收在一处；三个热区弹窗一行挂载。
   四个开面板回调（茶台 / 赌桌 / 观战 / 小院）补 `clearMovement()`，与榜单 / 告示板 / 聊天同一纪律。
2. **打赏走纯客户端拦截**：快捷按钮读钱包余额，`<10` 时禁用并把文案改成「余额不足」。
   不新增 opcode、不动双端——覆盖「余额不足」这一唯一可稳定复现的场景；目标离线等窄竞态
   仍静默，留待将来与 tip reject 包一并解决。
3. **P2P 回执补全仅补发送**：在 `respond()` 的过期 / 发起方离线 / 忙 / 上限 / 发起方冻结失败
   五个早退分支给应战方补一条 `S2C_P2P_INVITE_RESULT`。复用现有包，`accepted=false` +
   既有 reason 码，零协议改动、旧客户端照常解析。
4. **提示价值化与命中反馈**：给上香 / 摇钱树提示补收益说明；本人发泄命中时在受击点显示
   「命中」飘字（复用 `showFloatText`，非擂台场景，不与受方台词 / `showRingDamage` 重复）。

## 影响与回滚

- 全部改动都在既有通道内：**零新增 opcode、零协议改动、零存档变更、无需双端同步发版**。
- 回滚：删掉三个弹窗的 `useModalKeys` 调用与四个 `clearMovement()`；恢复快捷打赏按钮；
  撤掉 P2P 的 `sendResult` 补行；还原 HINT 文案与命中飘字。各自独立，互不牵连。
- 测试：新增 P2P 应战方回执单测（到期 / 离线两条）；全量 typecheck 与 test 通过
  （pixel-assets 50 / game-server 433 / web 897）。
- 版本工报已按 AGENTS.md 追加 `2026-11-16-17`。

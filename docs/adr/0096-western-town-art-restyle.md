# ADR-0096：园区美术从国风园林改成欧美小镇休闲风

- 状态：已采纳
- 日期：2026-11-15
- 关联：替代 ADR-0061 的视觉部分（摸鱼亭、财神供案、紫砂茶台、宫灯）、ADR-0063 的装饰配色、
  ADR-0091 的门牌骨架；沿用 ADR-0013（暖色低饱和与「同色相压暗」）、ADR-0048（局部动态光图）、
  ADR-0094（场所色板与焦点光），并遵守 `.codebuddy/skills/pixel-venue-polish`

## 背景

园区的核心玩法（摸鱼、上班、擂台、赌场、公寓）是当代职场梗，但地图上的装饰语言是国风园林：
朱红宫灯、重檐青瓦凉亭、红木供案与财神像、紫砂茶壶、朱漆对联与牌坊、太湖石盆景。两套语境叠在
一起，新玩家第一眼容易读成「仙侠 / 古镇」，与「打工园区」的设定对不上；对联、匾额这类竖排中文
在 6–8px 的字号下也几乎不可读。

需要一次性把地图上的中式装饰换成欧美小镇休闲风（木牌、白栅栏、黑色铁艺路灯、三角彩旗），
而**不能动任何玩法**：交互点、感应范围、提示文案、碰撞盒、座位坐标、协议字段、光源预算全部保留。

## 决策

### 1. 纯渲染层重绘，坐标与碰撞零改动

所有改动只落在 `Graphics` 绘制函数与调色板上。`WORLD_LAYOUT` 的几何常量（亭子八柱、四条石鼓凳、
供案与茶台碰撞底座、门牌落点、彩旗挂点）一行不动，因此 `layout-guofeng.test.ts` 的坐标断言、
`place-signs.test.ts` 的可达性断言继续有效。

### 2. 材料色板单点：`venue-palette.ts` 新增 `TOWN_MATERIALS`

牌坊、凉亭、神龛、饮品台、院门牌匾共用一份材料色（深胡桃木 / 白漆 / 奶油牌面 / 铁艺 / 铜件 /
灯罩玻璃 / 石砌），避免同一根木柱被四处绘制代码各写一份十六进制。取色纪律照旧：描边取同色相压暗，
不写纯黑；铁件用带蓝相的深灰。

`VENUE_COLORS.pavilion / shrine / tea` 三行由朱红调改木石调，`glow` 统一到暖白 `0xffc98a`。

### 3. 挂灯取代宫灯，灯数不变

`lighting/lanterns.ts` 的 `paintLantern()` 保持 9×22 占位，改画黑色铁艺挂灯（铁罩 + 玻璃芯 + 铁底托）；
`LANTERN_LIGHT.color` 由暖红改暖白，`flicker` 由 0.12 降到 0.06（电灯不抖），`radius 48` 与
`intensity 0.72` 不变。灯位数量（拱门 2 + 门柱 4 + 亭角 4 + 龛 2 + 彩旗 6）与 `MAX_LIGHTS` 预算不变。

### 4. 节日装饰换配色与灯串

`festival-decor.ts` 的布点纯函数一行不改（挂点、光心、6 盏预算、`?festival=0` 灰度开关全部保留）；
`festival-art.ts` 的三角旗改奶油 / 薄荷 / 珊瑚 / 天蓝，麻绳替朱红绳，彩旗中央的宫灯改成一串三只
玻璃小灯泡，树梢灯笼改小灯串。两帧飘动与 30s 昼夜 tint 采样不变。

### 5. 门牌去掉对联，数据字段同步精简

`DoorPlaque` 删除 `couplets` 与 `inkGold`：对联在 6px 字号下不可读，且中文竖排是国风专有形式。
`DOOR_PLAQUES` 的 `frame / text / x / depthY` 全部保留，门架几何（`POST_HALF 59`、`BEAM_TOP -78`、
`BOARD 64×20`）不变，只把朱漆换成木构 + 白漆横梁 + 奶油匾额 + 墨绿字。门楣彩旗仍压在横梁上方。

### 6. 建筑本体换材质，功能外观分离

- 摸鱼亭：飞檐改木瓦双坡顶 + 白漆封檐，朱红柱改白漆方柱 + 深木柱头，靠背栏杆改白色竖栏，宝顶改铜球；
- 祈福龛（原财神供案）：红木案改石砌龛体，财神像改铜马蹄铁，红烛改白蜡烛，青烟改白雾，金光改暖白；
- 饮品台（原紫砂茶台）：紫砂壶改不锈钢保温壶，品茗杯改白瓷马克杯，霓虹价签保留（ADR-0087）；
- 叠石：太湖石去透光孔，改圆润巨石 / 层叠石板，`PROP_SIZE` 与坐标不动。

交互判定（`isNearShrine` / `isNearTeaStation`）、提示文案（「上香祈福」「打开属性强化」）、
音效与气泡一律不在这里改。

### 7. 可回退

保留 `?festival=0`、`?light=0`、`?snow=0`、`?season=off` 等既有灰度开关：关掉装饰层与光图层后，
仍能对照新旧两套观感做验收。

## 影响

- **玩家**：地图整体从国风园林变成西式小镇；夜间挂灯由暖红改暖白，冷暖对比减弱但更接近路灯。
- **代码**：`DoorPlaque` 少两个字段，`plaques.ts` 少一套竖排文字逻辑；新增 `TOWN_MATERIALS`
  供五处复用。渲染层的贴图数量、光源数量、每帧开销均不变。
- **不改的部分**：所有玩法交互、碰撞、座位、协议、服务端 Tick、文案、竹丛植被与玩家国风装扮。

# ADR-0091：12 处场所统一挂中文门牌

- 状态：已采纳
- 日期：2026-11-15
- 关联：延伸 ADR-0061（门头牌匾与牌坊）、ADR-0063（门楣彩旗）、
  ADR-0089（导览牌按 `NAV_TARGETS` 派生）、ADR-0087（热区注册表与四栋建筑）

## 背景

ADR-0061 只给三处门头立了牌坊：工作区「难得糊涂」、会议室「画饼充饥」、宿舍区「安乐窝」。
卫生间、财神供案、游乐园、发泄区、八角笼、赌场、两栋小院与公寓全部没有门牌，
玩家走到设施前只能靠 HUD 导览卡或区域名确认位置；文艺匾额也看不出这里是「工作区」。

需求是「每个场所都要增加门牌，用中文名标注」。场所范围确认与 `NAV_TARGETS`
的 12 处导览目标一致，不把三湖、竹林这类自然景观算作场所。

## 决策

### 1. 12 处场所全覆盖，三种落法

| 场所 | 形态 | 位置 |
|---|---|---|
| 工作区 / 会议室 / 宿舍区 | `gate`：沿用 ADR-0061 的两柱牌坊 | 门线中心不变 |
| 卫生间 / 财神供案 / 游乐园 / 发泄区 / 绩效八角笼 / 摸鱼大赌场 / 牛马公寓 | `board`：新增 60×32 小门牌 | 入口侧前方 |
| 摸鱼一号院 / 摸鱼二号院 | 院门既有牌匾加一行院名 | `villas-view.ts` |

四角房保留牌坊是因为匾额与对联已经挂在横枋上，拆掉会同时失去工作区那副对联；
其余 7 处没有门框可挂，才在入口立小牌。两栋小院的院门夹道只有 50px，立牌会挡路，
因此把院名并进既有牌匾，信息层级变成「院名 → 待售 / 房主名」。

### 2. 文案只从 `NAV_TARGETS` 派生

`DoorPlaque` 新增 `id: NavTargetId` 与 `frame: 'gate' | 'board'`，`DOOR_PLAQUES`
下移到 `NAV_TARGETS` 之后，`text` 由 `navName(id)` 取导览目标的中文名。
场所改名只改 `NAV_SOURCES` 一处，牌面、HUD 卡与指路牌同时跟上。

大牌坊的「工 作 区」字距由渲染端补（`spacedLabel()`），数据里仍是标准名，
测试因此可以直接断言 `plaque.text === target.name`。

### 3. 小门牌是纯装饰，几何写死在渲染层

- 匾面 56×18、总高 32：横幅 + 左右 4px 短柱 + 石座，深漆底 + 上下 1px 金边 + 8px 金色中文；
- 不登记 `solids`、不进 `WORLD_LAYOUT.solids`、不进协议与落盘（ADR-0004 / ADR-0081）；
- 仍以底边中心锚 `depthY` 进 `SortLayer`，与树、桌椅、角色共用一套遮挡；
- `Text` 构造期建好，帧循环零写入，DPR 变化走 `setTextResolution`（ADR-0013）。

### 4. 门楣彩旗只挂在牌坊上

ADR-0063 的 `gateAnchors()` 从 `DOOR_PLAQUES` 派生门楣彩旗。列表从 3 条涨到 10 条后
若不过滤，会多出 7 条没有横枋可挂的彩旗，既悬空又过密。现在只取 `frame === 'gate'`
的三座牌坊，卫生间那条例外补挂保留，彩旗仍是 4 条，`festival-decor.test.ts` 断言不变。

### 5. 落点用测试钉住

新增 `place-signs.test.ts`：12 处 id 全覆盖且不重复、文案等于导览名、只有四角房是
`gate`、只有工作区带对联、每个落点 `isOnLand` 且 `!isBlocked`、不压导览到达点。
坐标全部从 `WORKROOM_GATE` / `RESTROOM` / `SHRINE_ALTAR` / `PARK_SOUTH_GATE` /
`BOSS_ARENA` / `RING_SIGNUP` / `DICE_HALL_APRON` / `APARTMENT_DOOR` 派生，不写第二份世界坐标。

## 备选方案

| 方案 | 收益 | 代价 | 结论 |
|---|---|---|---|
| A. 12 处全换小门牌 | 形态最统一 | 丢掉工作区牌坊与对联，需重做门头 | 否决 |
| B. 12 处全立大牌坊 | 视觉最气派 | 148 宽牌坊会压游乐场南门、八角笼南门与赌场动线 | 否决 |
| C. 悬浮 UI 标签跟随镜头 | 不受地形限制 | 不是场景实体，破坏像素世界的遮挡关系，且要处理缩放 | 否决 |
| D. 牌坊 + 小门牌 + 院名增行（采纳） | 覆盖 12 处、不挡路、保留对联 | 需维护两种门牌几何 | 采纳 |

## 后果

- `DOOR_PLAQUES` 从 3 条变 10 条，`DoorPlaque` 新增 `id` / `frame`；两栋小院不在表内；
- `PlaqueView` 按 `frame` 分支绘制，小门牌新增一套 60×32 几何；
- `villas-view.ts` 的院门牌匾从 22 高变 26，上行 7px 院名、下行 9px 归属；
- 门楣彩旗仍 4 条，光池预算不变，服务端零改动、零新增落盘；
- 回归口径：`place-signs.test.ts`（12 处覆盖与落点）、`festival-decor.test.ts`（4 条门楣）、
  `nav-arrival.test.ts`（12 处到达点）、`layout-guofeng.test.ts`（国风地标不重叠）。

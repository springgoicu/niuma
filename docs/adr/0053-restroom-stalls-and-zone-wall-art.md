# ADR-0053：卫生间每侧三格坑位，内隔墙按共享碰撞体绘制

- 状态：已采纳
- 日期：2026-11-12
- 关联：ADR-0044（四角院落与卫生间三区）、ADR-0026（座位种类与房间陈设）、ADR-0046（室内陈设补完层）、ADR-0012（地形碰撞）

## 背景

两个问题同时暴露：

1. **空气墙。** 卫生间两道 10px 内隔墙（男 / 洗手池 / 女的分界）只写进了 `CAMPUS_SOLIDS`，没有任何贴图。
   `props.ts` 的地面层本来会把所有 `kind: 'wall'` 压成扁平矩形，但 `interior-art.ts` 的薄荷马赛克
   是在地面层之后整块铺满室内的（`base.addChild(flat)` 晚于 `ground`），把这两道墙连同它们的门洞一起盖掉了。
   玩家的实际体验是：走到门洞之外会撞到一道看不见的墙，而 60px 门洞本身也看不见。
2. **坑位偏少。** 一条北墙每侧只有 2 个坑位（男女各 2，全房 4 个），房间南半区
   （坑位前缘到南墙 196px）几乎全空。房间 460×360 不再放大，所以只能重新排。

## 决策

### 1. 坑位表成为唯一真相（`campus.ts`）

```text
STALL_WIDTHS = [42, 44, 42]        // 净宽，合计 42+6+44+6+42 = 140 = 一个分区整宽
STALL_PARTITION_W = 6              // 隔断宽
STALL_PARTITION_H = 154            // 隔断进深（与旧版一致）
RESTROOM_STALLS: RestroomStall[]   // 6 条：{ x, y, w, h, partition }
```

- 男区从西墙内侧起排（x+10），女区从第二道内隔墙内侧起排（x+310）；宽度首尾对称，
  所以女区从东往西排天然是镜像，不需要额外翻转；
- `CAMPUS_SEATS` 的马桶（`x = 格子中点`）、`CAMPUS_SOLIDS` 的隔断（`partition`）、
  渲染层的隔间（同一张表）三处都从这张表派生——以前是三份手写常量；
- 相邻两坑相距 49px，仍满足座位表「两两间距 > 40」的既有断言；马桶精灵 22px 宽，
  在 42 / 44 的净宽里两侧各留 10–11px。

### 2. 内隔墙的门洞移到坑位前缘

门洞从 `y+200…y+260` 移到 `y+164…y+224`（`y+10+STALL_PARTITION_H` 起 60px），
正好与坑位排的前缘齐平：从北门进来沿中央区走到这里，侧身就是男 / 女区，
不用先绕到房间最南端再折回来。门洞宽度仍是 60px，与另外三扇房门同一档。

### 3. 内隔墙的贴图从共享 solids 反查

`interior-art.ts` 新增 `innerWalls(room)`：在 `WORLD_LAYOUT.solids` 里筛
「`kind === 'wall'`、宽度不超过两堵墙、两端都不贴外圈」的纵向墙段，再用与外墙同色的
冷白墙面 + 亮压顶 + 暗收边画出来。这类「碰撞在共享层、贴图在渲染层」的东西以后不会再各自漂一半：
墙改了渲染跟着改，不再需要第二份坐标。

## 备选方案

| 方案 | 结论 | 理由 |
|---|---|---|
| A 只补画两道内隔墙 | 必做但不充分 | 修掉空气墙，坑位仍是 4 个 |
| B 拆掉三区分隔，整条北墙排 8 格 | 不选 | 北门正对北墙中段，门会开进坑里；也抹掉 ADR-0044 的男女分区 |
| C 每侧 4 格 | 不选 | 4×44 + 3×6 = 194 > 140，必须把中间洗手区压到 60 以下，装不下 60px 北门与洗手台 |
| D 每侧 3 格，隔断与门扇都由共享表派生 | 选用 | 尺寸不变、容量 +50%，渲染不再复制坐标 |

## 后果

### 正面

- 坑位 4 → 6（每侧 3 格），座位总数 27 → 29（工作区 8 + 会议 8 + 马桶 6 + 宿舍 7）；
- 空气墙消失：内隔墙、门垛、隔间门扇与 60px 门洞都看得见，撞到的每一处都有对应的像素；
- 加法只落在布局数据上：`SeatKind`、协议、服务端 tick、`findNearestSeat` 全部不动。

### 负面 / 风险

- 座位 id 整体后移 2（马桶在会议椅之后、端椅之前）：`CAREER`/`SEAT_STATE` 里只有运行期 id，
  进程重启即清空，没有落库迁移；
- 静态内容改动必须双端一起发版（README「改地图要双端一起发版」）；
- 马桶仍在一条北墙上：想要 8 格以上就必须让马桶朝北坐（水箱在南），那需要翻转贴图与新的 `facing` 分支，
  本期不做。

### 回滚

- `STALL_WIDTHS` 改成两格（例如 `[67, 67]`）即可回到 4 坑，其余代码不动；
- 或整条 revert 本次提交：`RESTROOM_STALLS` 与测试断言同时回到 4 坑，双方一起发版。

## 复核信号

- [ ] 坑位需要继续增加（≥ 8）→ 先解决「马桶朝北」的贴图与 `seatLift`，再谈排布；
- [ ] 中央洗手区被继续压窄 → 60px 门洞与两个洗手台先冲突，应改为侧墙洗手台；
- [ ] 再次出现「能撞到、但看不见」的矩形 → 在渲染层统一走 solids 反查，禁止手写第二份坐标。

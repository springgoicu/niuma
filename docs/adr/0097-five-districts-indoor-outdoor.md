# ADR-0097：园区重做成五区小城，室内外第一次成为数据

- 状态：已采纳
- 日期：2026-11-15
- 关联：改写 ADR-0044（四角院落）、ADR-0077（岛界与院落）、ADR-0070（发泄区位置）、
  ADR-0087（赌场入驻）、ADR-0095（六栋公寓落点）、ADR-0091（场所门牌）、
  ADR-0089（指路牌画布）；沿用 ADR-0036（导览）、ADR-0081（共享运行态）

## 背景

ADR-0044 之后，园区的骨架是「中央广场被四角院落围住，其余设施绕着岛乱撒」：

- 企业相关的只有工作区与会议室，发泄区（老板）却在南侧庭院，卫生间还占着企业侧的一角；
- 赌场在西侧草带、八角笼在西南角、游乐园在北端，三个游乐设施分散在三个方向；
- 影音室与小黑屋贴着南向主路，公寓六栋绕广场散开，急救站独在东南；
- 导览卡只有「室内 / 园区」两档，无法表达「这里属于哪个区」；
- 走进任何一处，地面与建筑缺少统一的「街区感」，读起来像一堆摆件。

需求是「区分室内和室外场景、归拢场所，使其更像一个完整的城市/园区」。

## 决策

### 1. 五个大区 + 中央广场

| 区 | 归属场所 | 主场景 |
|---|---|---|
| 企业区 | 工作区、会议室、发泄室、财神供案、紫砂茶台 | 室内 |
| 游乐区 | 摸鱼大赌场（半开敞）、游乐大街、游乐园、绩效八角笼 | 室外 |
| 生活区 | 六栋牛马公寓、宿舍区、家庭影音室、两栋小院 | 室内 |
| 服务区 | 卫生间、小黑屋、护士急救站 | 室内 + 站台 |
| 景观区 | 摸鱼湖、沉思浅塘、涟漪湖、摸鱼亭、竹林、花海 | 室外 |

中央迎宾广场保持 (4096,4096)、半径 360、出生点与迎宾拱门不动，成为五条街的起点。

### 2. `districts.ts` 是分区与室内外的唯一真相

新增 `packages/shared-types/src/world/districts.ts`，导出：

- `DISTRICTS`：每区 `id / name / scene / rects / gate / color`，`rects` 是数组，
  所以景观区可以是「三湖 + 摸鱼亭 + 竹林」的网络，不必硬凑成一块；
- `VENUES`：每个场所的 `id / name / district / scene / rect / navId`，坐标一律从
  各场所模块的常量取，**不写第二份坐标**；
- `NAV_TARGETS` / `NAV_ARRIVALS` / `NavTargetId` 从 `layout.ts` 搬到这里，
  `NavTarget.area`（`indoor | grounds`）换成 `district` + `scene`；
- `districtAt()` / `venueAt()` 为纯矩形命中，无分配。

依赖只有一个方向：场所模块 → `districts.ts` → `layout.ts` → 渲染 / 导览 / 服务端。
为此把急救站常量拆到 `world/clinic.ts`、摸鱼亭拆到 `world/pavilion.ts`，
财神供案与茶台并回 `world/campus.ts`。

`regionAt()` 改为四段：中央圆庭 → 场所名 → 中央迎宾带 → 大区名 → `园区野地`。

### 3. 企业楼：一栋 920×760 的两层小楼

旧院落 1520×1240 围住广场，改成一栋紧凑小楼落在广场正西：

```
CAMPUS_RECT 2620,3200  920×760
├─ 北排：工作区 460×360（西北，朝走廊整段敞口）｜ 会议室 460×360（东北，南墙开门）
├─ 走廊：y 3560–3600，东端敞口 = 公司大门
└─ 南排：发泄室 920×360（橡胶地 + 老板，北墙开门）
```

- 工作区仍不加内墙，但补上了楼体北 / 西外墙，走进草地再进楼能读出「进了一栋楼」；
- 发泄室取代原先南侧庭院的橡胶垫：`BOSS_ARENA` 改为「发泄室内 420×300 的垫子」，
  老板、脚底碰撞、受击区与每日回满全部照旧；
- 卫生间从企业侧迁出，独立立在服务区广场北侧，尺寸仍是 340×300（三区不变）。

### 4. 服务区：一个 860×860 的公共广场

卫生间、小黑屋、急救站面向同一个铺装广场，门都开向广场：

| 场所 | 落点 | 门 |
|---|---|---|
| 卫生间 | 4600,3660 340×300 | 北门，正对广场 |
| 小黑屋 | 4600,4040 320×240 | 西门，出门就是广场 |
| 急救站 | 5060,3660 248×210 | 西侧人行门 + 南侧救护车通道 |

急救站的围挡、拦停位、进站航点全部由 `CLINIC_RECT` 派生，救援车不再绕研发园，
改成「服务广场南沿 → 东主路 → 中央广场」。

### 5. 游乐区：一条游乐大街串起三个玩法

- 摸鱼大赌场搬到 2600,2620（街西端），南侧铺装直接落在街面；
- 绩效八角笼搬到 3140,2760（街中段路南），围栏、报名点、观战长椅、领奖台全部随矩形派生；
- 游乐园 1080×600 原地不动，南门正对北向主路；
- 新增 `AMUSEMENT_STREET`（2600,3020 1440×96）把三者连成一条街。

### 6. 生活区：两排联排 + 一条生活大街

- 六栋 300×240 公寓改成两排：行 y 4680 / 5040，列 x 3200 / 3540 / 4240（南向主路从中间穿过）；
- 宿舍区 460×360 迁到 3820,5400；影音室 460×320 迁到 3200,5400；两栋小院并排到 4300/4560,5390；
- 新增 `LIVING_AVENUE`（3140,5300 1460×80）串起所有门；
- 楼间巷宽从 ADR-0095 的 300px 收到 40px——联排是城市住宅的读法，门口仍要能站人，
  因此 `isPlantable` 对每栋楼的留白从 40 提到 60，树不会堵门。

### 7. 景观区：不搬湖，只认领

三湖的形状与位置一个字都没改：湖岸贴图、游鱼、涉水判定与全部留白规则都挂在多边形上，
硬搬成一片要连带重做这些。景观区因此定义为「水景与绿地网络」，在西主路尽头设区门；
竹林与花海移到西带与东南草甸，避开新区建筑。

### 8. 五座区门 + 门牌体系

- 每区一个 `gate`：门框、区色匾额、一盏低强度门灯都由 `DISTRICTS` 派生；
- 世界指路牌不再罗列 12 处设施，只列 **五座区门**（`signPlates` 读 `districtReadings`），
  96×120 画布仍放得下；
- HUD 导览卡按五区分组，每行加「室内 / 室外 / 半开敞」徽标，卡底显示「企业区 · 工作区」；
- 门牌仍是 12 块，但只有企业楼保留木构牌坊，其余 9 处 + 卫生间门洞改用小门牌 / 门楣彩旗。

### 9. 表现层

- 新增 `street` 与 `vent` 两档场所色板；五区街面统一浅石青，靠区色收边与门前门垫分区；
- 小地图在建筑之上薄铺一层区色（18% 不透明度），先读出「哪一片」；
- 光位从 24 盏增到 30 盏（五座区门各 1 + 发泄室 1），仍远低于 `MAX_LIGHTS = 96`；
- `?venue=0` 整层可关，区门与发泄室地面与既有的场所层一起进退。

## 备选方案

| 方案 | 收益 | 代价 | 结论 |
|---|---|---|---|
| A. 只加 `district` 标注，不动坐标 | 改动最小 | 设施仍分散，读不出城市结构 | 否决 |
| B. 保留四角院落，只把设施往四角塞 | 企业楼与广场关系不变 | 1520×1240 的院落放不进广场四周的任何一条街，发泄室/赌场仍会被挤到墙角 | 否决 |
| C. 五区 + 企业楼压成两排（采纳） | 分区清楚、室内外可读、坐标仍全部派生 | 大量坐标搬迁，布局测试整体重写 | 采纳 |

## 后果

- `NAV_TARGETS` 的 12 个 id 顺序重排（企业区 4 → 游乐区 3 → 生活区 4 → 服务区 1），
  `NavTarget.area` 字段删除；只有 `NavCard`、`signpost` 与三个测试读它，硬切成本低于双语义；
- `SOUTH_YARD` / `SOUTH_YARD_PAVING` / `SOUTH_YARD_PROPS` 退场，换成
  `LIVING_AVENUE` / `AMUSEMENT_STREET` / `SERVICE_SQUARE` / `COMPANY_FORECOURT`；
- 座位 id 仍遵守「只能追加、不能插队」：工位 → 会议椅/马桶 → 宿舍床/沙发/凳 → 石鼓凳 →
  沙发右半 → 影厅椅 → 长椅 → 病床 → 赌桌圆凳 → 观战长椅。长椅数量不变，`seatId` 不漂移；
- 地图是静态内容，**必须双端同版本发布**：只发一端会出现「看得到楼、走不过去」；
- 落盘范围不动：本轮没有新增 `world-state.json` 字段，协议一个字节没改；
- 服务端口径随常量走：押送寻路起点改为服务广场、救护车航点改为广场南沿与东主路，
  相关用例从硬编码坐标改为从 `JAIL_*` / `CLINIC_*` / `SERVICE_SQUARE` 派生；
- 回归口径：`campus-layout` / `boss-layout` / `jail-layout` / `clinic-layout` /
  `apartment-layout` / `theater-park-layout` / `nav-arrival` / `place-signs` /
  `layout-hub` / `layout-density` / `collision` / `seats`，以及 web 侧 `nav` / `signpost` /
  `festival-decor` / `lighting` 与服务端 `escort*` / `clinic`。

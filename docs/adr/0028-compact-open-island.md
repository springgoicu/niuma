# ADR-0028：海岛再缩 30%，删除围栏改开放式办公区，水系与物件加密

- 状态：已采纳
- 日期：2026-11-11
- 关联：修订 ADR-0010（尺度总则）、ADR-0012（海岛边界）、ADR-0022（紧凑世界与镜头倍率）、
  ADR-0026（紧凑海岛与工作/休息室）、ADR-0027（工位桌四向几何）

## 背景

四条反馈都指向同一件事——地图还是大、东西还是散：

1. **地图仍然太大**：上一轮收到 5436×6018 之后，广场到研发园仍要走约 1100px，
   一屏（约 1707×960）看不到大半个功能区，四角还有成片纯草。
2. **围栏把办公区圈成了「院子」**：四个门洞是唯一的进出路径，视觉上是一道横穿画面的木栅栏；
   而围栏本身除了挡人没有任何玩法。
3. **水系太单薄**：只有一条南北向的周报河与一座木桥，湖在东南角，中间大片陆地没有水。
4. **物件仍然偏散**：林地 6 片、花海 4 片、水塘 2 口，走到林地边缘就开始出现「只有草」的走廊。

## 问题

四条互相牵制：

- 只缩岛不加密，物件密度会被动上升，但岛边缘仍是空的；只加密不缩岛，走一圈的时间不变。
- 删围栏会让办公区失去边界：工位沿内圈排布、四个门洞的通道、区域名「办公区」全都挂在围栏矩形上，
  直接删字段会让工位与测试一起失去锚点。
- 加河就必然要加桥：南北向的河只需要东西向桥，东西向的溪需要南北向桥。
  现有 `addBridges` 把「木板缝竖排、栏杆压上下沿」写死成东西向，直接复用会让栏杆横在路中间。
- 岛的西南湾是深凹的海湾，缩到 0.7 后它会吃掉整片南段陆地，研发园与湖就没有地方放。

## 备选方案

| 方案 | 收益 | 代价 | 不可逆性 |
|---|---|---|---|
| A. 只删围栏 + 加密，岛不动 | 改动面最小 | 「地图还是太大」没解决 | 低 |
| B. 缩岛 30%，保留围栏，只加物件 | 通行时间下降 | 围栏仍是唯一出入口，开放式分区做不了 | 低 |
| C. 缩岛 30% + 删围栏 + 水系与密度加密（采纳） | 四条反馈一次收口，岛与内容同向收紧 | 布局常量整体重排，双端必须同版本发布 | 中 |
| D. 同时把 `WORLD_WIDTH/HEIGHT` 从 8192 调小 | 世界常量更贴内容 | 定点坐标上限、AOI 网格、海面平铺、相机夹取全部连带，收益只是少铺几块海面 | 高 |

选 C。A 与 B 各留一半问题；D 把钱花在看不见的地方。

## 决策

1. **只缩岛，不动世界画布**。`WORLD_WIDTH/HEIGHT` 仍是 8192：它同时被定点量化上限、
   AOI 网格、海面平铺与相机夹取引用，改它会扩散到协议与网络层。
2. **岛按 0.7 收缩**：以 (4096,4096) 为原点，对海岸线、河、湖、林地、道路做一次等比收缩，
   岛从 5436×6018 收到 **3805×4212**（x 2146–5951 / y 1956–6168，面积约 −48%）。
   坐标全部四舍五入后写死为字面量，运行期不缩放，也不使用 `Math.random / Math.sin / Math.cos`。
3. **西南湾填成陆地，改成湿地水塘群**：上一版的西南深湾在 0.7 尺寸下会切掉整片可玩陆地，
   南段就放不下研发园与湖。填平后岛形变成「三个海湾 + 一块完整南段」，
   原海湾位置改成 P1/P2 两口水塘、两片林地与一条码头栈道。
4. **删除围栏**：`WorldLayout.fence` 字段、`FenceSegment` 类型、`collision.ts` 的 segment blocker、
   `terrain.ts` 的 `addFence / drawFenceSpan / FENCE_POST_GAP`、小地图的 fence 描边一并删除。
   区域名「办公区」改挂到无碰撞的 `WorldLayout.office`（1760×1384，就是上一版围栏的包围盒）。
   **删字段而不是留空数组**：编译器会把所有消费方找出来，不会留下永远不命中的分支。
5. **开放式办公区与软分区**：工位排布逻辑从 `FENCE_RECT` 换成 `OFFICE_RECT`，仍是四面围一圈、
   四个方向各留一条 272 宽的入口通道（约 34 个工位）。软边界新增 `PropKind.hedge`
   （32×18 的树篱段，沿四边每 64px 一段、入口留 350 缺口），走 props 管线，
   **不产生 blocker**——视觉上分区、脚上不封路。花箱加密到 26 个，广场内再补咖啡座、长椅与灯柱。
6. **水系加密**：
   - 主河「周报河」改到岛西侧纵贯（中心线 x 2696–2734，水面 2584–2846），南北两端探进海里；
   - 新增东西向支流「晨会溪」（半宽 72，水面 y 4868–5012），从主河分出、汇进东湾，
     北岸离办公区南缘 80px、南岸离研发园北缘 88px；
   - 摸鱼湖收到东南角（12 点手写，600×640），另布 P1–P5 五口 12 边水塘；
   - 三座木桥：西向路跨主河（东西向）、南向主路与东侧支路跨晨会溪（南北向）；
   - 两座码头：湖北岸与主河西岸，单独建模为 `WorldLayout.docks`，与桥共用 `isOnBridge` 放行。
7. **桥与码头按通行方向绘制**：`addDeck(rect, rail)` 用 `h > w` 判断南北向，
   南北向时木板缝横排、栏杆压左右沿；码头不设栏杆。写死一个方向会让南北向桥的栏杆横在路中间。
8. **建筑聚簇改成「原点 + 相对偏移」**：`campus.ts` 抽出 `CAMPUS_ORIGIN / LOUNGE_ORIGIN /
   WORKROOM_ORIGIN`，五处建筑的全部陈设（墙、门、桌、椅、床、马桶、绿植、铺装）写成
   `原点 + 相对偏移`。重排聚簇只改三行，数字仍然全部手写。
   休息室移到北岸（2880–3240），工作区留在办公区东翼（5100–5550），研发园整体南移到 5100–5900。
9. **密度加密**：
   - 林地 6 → 7 片（北带两片、西岸三片、东南角一片、北带东段一片），`TREE_CELL` 120 → 96、
     `TREE_CHANCE` 0.7 → 0.92，林地树约 214 棵；
   - 孤树 `WILD_TREE_CELL` 130 → 88、`CHANCE` 0.9 → 0.99、`MIN_GAP` 170 → 112，
     并改用一套更宽松的留白（树冠压到路边、塘边是自然的），约 79 棵；
   - 花海 4 片，新增东南角一片；
   - 沿路新增 6 组休息角（灯 + 长椅 + 垃圾桶 / 野餐桌），北岸补一条绕湾横路。
10. **新增空地密度测试** `layout-density.test.ts`：64px 栅格采样岛屿，
    纯草格占全部陆地 < 20%，任意 512×512 陆地窗口 < 45%，并锁定水系（2 河 / 6 湖 / 3 桥 / 2 码头）、
    林地 7 片与花海 4 片的数量。

## 后果

- 正面：
  - 岛面积减半，广场到研发园、到东西两翼的步行时间同比缩短；一屏能看到广场、道路、水面与林地；
  - 围栏删除后办公区与草地连成一片，树篱 + 花箱把空间切成可读的小块，不再是一道横穿画面的木栏；
  - 水系从「一河一湖」变成「两河六湖三桥两码头」，桥成了真实的路径节点而不是装饰；
  - 聚簇原点化之后，后续再挪房间只改三行，不会再出现「墙挪了、椅子没挪」。
- 负面：
  - **世界坐标是双端共用的常量**，本次必须双端同版本发布，旧客户端连新服务端会被持续拉回；
  - 桥与码头共用 `isOnBridge` 放行水面，玩家可以站在码头上，但码头边缘 9px 内仍会落进水里——
    这是既有桥面行为，没有新增「落水」状态；
  - 树篱是纯装饰，玩家可以穿过；若以后要做「不可穿越的绿篱」，必须新增 blocker 并重新跑密度测试；
  - 南北向桥的栏杆方向由宽高比推断，桥若画成正方形（w == h）会退化成东西向。
    当前三座桥都满足 `h > w` 或 `w > h` 的明确关系，新增桥时必须保持。
- 回滚成本：中。布局常量与三处围栏清理一起回退即可，但必须与 `game-server` 同时回退；
  `hedge` 道具与码头渲染可以单独保留（不依赖协议）。

## 复核信号

- 出现「树长进水里 / 花海压到路」：先看新坐标是否越过了水面 95px 留白与道路 55px 留白；
- 出现「任意 512 窗口仍然很空」：按 `layout-density.test.ts` 的采样点补林地或水塘，
  不要直接把阈值放宽——阈值是这次改动的一半目的；
- 出现「孤树不足 60」：先调 `WILD_TREE_CHANCE`，再动 `WILD_TREE_MIN_GAP`
  （112 是树冠 56–62 与角色 48 之间还能看出「独立一棵」的下限）；
- 出现「栏杆横在路中间」：检查桥的 `h > w` 与通行方向是否一致，`addDeck` 只按这个比例判断；
- 出现「从办公区出门就撞树篱」：树篱无碰撞，撞的是工位桌或花箱，检查 `OFFICE_RECT` 四边的入口缺口；
- 出现帧率下降：按 ADR-0015 的顺序降密度，先野花、再孤树，最后才动林地格距。

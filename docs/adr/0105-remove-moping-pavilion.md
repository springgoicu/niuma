# ADR-0105：拆除摸鱼亭，湖东北岸回归草地

- 状态：已采纳
- 日期：2026-11-16
- 关联：修订 ADR-0061（摸鱼亭诞生）、ADR-0077（亭子随湖迁到北岸）、ADR-0095 / ADR-0096（周边留白与西式木构重绘）、
  ADR-0097（景观区场所表）、ADR-0099（补进导览）、ADR-0100（亭内弱交互）；
  沿用 ADR-0078（导览只列可互动场所）、ADR-0081（落盘范围）、ADR-0101（撤掉的地面要收尾）

## 背景

摸鱼亭从 ADR-0061 起就是景观区的地标：八根亭柱、双坡屋顶、一张石桌、四张石鼓凳，ADR-0096 又把国风重檐
改画成西式木构凉亭。它确实是地图上最好认的一处建筑，但玩法只有「坐一下、按 F 发呆」：

- 四张石鼓凳要单独一种 `drum` 座位，拖着座位几何、贴图烘焙、工牌文案与「静置气泡」一张台词表；
- 八根亭柱进碰撞表、四盏亭角灯进光预算、亭子自己一套后景/前景双深度键、冬季积雪与亭前湖面专属反光；
- 一个导览目标 + 一块入口小门牌 + 一条到达横幅副标题，全部只为「走过去看湖」这一件事。

ADR-0101 把六栋公寓收敛成一栋之后，地图的取向已经明确为「少而实」：能按 F 的地方留下，只剩观赏的建筑
不占地块与预算。摸鱼湖的北岸本身是连续草地，亭子撤掉后湖岸线与草地能直接接上，不需要补新地景。

## 决策

### 1. 连玩法一起删，不做「只删外观」

删除范围：共享层 `world/pavilion.ts`（占地、八柱碰撞、四凳、石桌）、客户端 `PavilionView`、
`SeatKind` 的 `drum` 与对应贴图/座位几何、导览目标 `pavilion`、场所表条目、区域名、入口门牌、
`HINT.pavilion`（含按钮与触屏两条映射）、禅意台词表与静置节流、到达横幅副标题、亭子地面影子与亭前湖面反光。

保留：摸鱼大赌场的亭台与工作区茶台小亭不动——那两处是玩法场地，不属于「观赏亭子」。

### 2. 原址保留一块 200×180 的景观区草地

`SCENERY_RECTS` 里原来那一块 `rectExpanded(PAVILION_RECT, 30)` 换成同址的 200×180 字面量。
直接删干净会让 `regionAt` 在该处回落到 `园区野地`，小地图也会出现一块没有区色的空洞。
新地块零碰撞、零灯光、零地标，只承担区界与区域名，做法沿用 ADR-0101「撤掉建筑的地要收尾」。

### 3. 座位 id 前移，不升快照版本，改在服务端加护栏

`SEAT_DRAFTS` 的 id 等于「下标 + 1」，删掉中间四张石鼓凳会让其后所有座位（宿舍沙发、影厅 15 座、
园内长椅、病床、赌桌圆凳、观战长椅）整体前移 4。

升 `SNAPSHOT_VERSION` 会让所有玩家的落点一起失效，代价远大于收益。改为在 `resolveSpawn` 里核对
上报坐标：座位锚点与 `resume.x / y` 的距离超过 64px 就不认座，按上报坐标落地。正常存档里两者相等，
只会拦掉「旧 id 指向了另一张远处的椅子」这一种错位。

### 4. 景观区不再有导览目标

导览只列可互动场所（ADR-0078 的口径），摸鱼亭是景观区唯一的目标。删掉后导览从 15 处变 14 处，
`NavCard` 已按「空组不占位」过滤，组件不需要改。景观区改为步行前往。

### 5. 光源预算与树木留白

- 亭角 4 盏灯撤掉后常驻光源 −4，`MAX_LIGHTS = 96` 不动，回收的余量留给后续动态光源；
- `isPlantable` 删掉 `rectExpanded(PAVILION_RECT, 40)` 的排除，树与花可以自然长回原址，
  水面 95px 的留白规则保持不变。

## 后果

- 导览目标 15 → 14、入口门牌 12 → 11、场所 20 → 19、座位 −4、碰撞体 −8、常驻光源 −4；
- 「景观区」仍有区界、区门与小地图填色，但导览卡里不再有该分组；
- 原亭址变成可自由穿行的草地，旧截图、攻略与玩家记忆里的方位会失效；
- 老存档的 `seatId` 可能指向另一张椅子，由 64px 护栏兜住，最坏情况是从草地上站起来；
- 测试口径同步：`layout-guofeng` / `nav-arrival` / `districts` / `place-signs` / `nav` / `pathfinding` /
  `road-graph` / `lighting` / `ritual` / `venue-spots` / `context-hint` / `seat-art` / `resume`；
- 回滚成本中等：恢复被删模块、四张座位、八条碰撞、门牌与导览条目，测试一起回退即可。

## 备选方案

- **只删外观、保留座位与导览**：地上留四张石鼓凳和一张石桌却没有顶，读起来像「亭子塌了」；
  维护成本也一分没省，导览里仍会出现一个只能坐着发呆的目标。
- **只把亭子移出导览、世界保留**：ADR-0078 已经对「把不能互动的场地留在导览里」投过否决票，
  反过来保留一处没有入口的亭子，只是把噪音从导览挪到「走过去才发现没用」。
- **原地改露天小景（留石桌石凳或长椅）**：需要新增本地点、静置演出与碰撞，等于换一套弱交互继续维护；
  这次的需求是「拆掉亭子、恢复草地」，不再新增地标。
- **把摸鱼湖补进导览**：湖是纯观赏水面，补进去会重犯 ADR-0078 的「导览列观赏区」问题；
  而且湖面不可站立，只能把到达点放在岸上，与「点一下就过去」的预期不符。

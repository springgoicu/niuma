# ADR-0077：地图再收紧 20%，卫生间与小黑屋改小，游乐园北移

- 状态：已采纳
- 日期：2026-11-13
- 关联：修订 ADR-0028（紧凑海岛）、ADR-0044（四角院落）、ADR-0047（中央枢纽与三湖）、
  ADR-0053（卫生间坑位）、ADR-0061（摸鱼亭）、ADR-0064（矩形岛界）、ADR-0067（游乐园静态化）、
  ADR-0070（发泄区）、ADR-0072（小黑屋执法）

## 背景

产品反馈集中在三件事：

1. **地图还是散**：岛从 5436×6018 收到 3805×4212 后，广场到游乐园、到东南摸鱼湖仍要走 1500px 以上，
   一屏之内读不到「场所在哪」，岛边缘还有「走一段只有草」的走廊。
2. **卫生间太大**：460×360 的房间只服务 3 + 3 个坑位，两块分区在没人时是空房。
3. **小黑屋太大**：460×320 与家庭影音室同尺寸，但里面只有一张反省凳与三个并排位。

约束：

- 坐标必须手写整数，布局层禁止 `Math.random / Math.sin / Math.cos`，**不做运行期缩放**（ADR-0028）；
- `WORLD_WIDTH/HEIGHT` 保持 8192，改画布会扩散到定点量化、AOI 网格与相机夹取；
- 中央广场、出生点、四角院落（工作区 / 会议室 / 宿舍区）、欢迎地标与广场陈设不动，控制爆炸半径；
- 三湖各有 6 条纯客户端小鱼，鱼窝离岸 ≥60、鱼间距 ≥100，湖形不能随手改。

## 备选方案

| 方案 | 收益 | 代价 | 不可逆性 |
|---|---|---|---|
| A. 只改两间房，地图不动 | 改动面最小 | 「场所太散」没解决，岛边仍是空草 | 低 |
| B. 岛界收紧 20%，但所有场所等比缩放 | 密度最高 | 房间内的桌椅、坑位、影厅座椅会一起缩，手感与可读性都被破坏 | 中 |
| C. 岛界收紧 20%，只挪场所位置、不改建筑内部尺寸（采纳） | 步行变短且房间仍然好走 | 道路、道具、树丛、花海与测试要整体重排 | 中 |
| D. 再收紧 30% | 最紧凑 | 南庭院与游乐园无法并排，游乐园只能缩形 | 高 |

选 C。B 会让「角色 48 texel、桌 88×40」这套尺度失效；D 会把游乐园挤到必须改内部布局。

## 决策

### 1. 岛界 3040×3368

矩形陆地从 x 2146–5951 / y 1956–6168 收到 **x 2560–5600 / y 2412–5780**，
面积约 −36%，边界仍是四条直边 + 26px 沙滩带（ADR-0064 不变）。
`WORLD_BOUNDS / isOnLand / isBlocked / 相机夹取 / 小地图 / NPC 采样 / 押送 BFS 网格` 全部从这一份常量派生。

### 2. 卫生间 340×300，四个坑位

- `RESTROOM = { 4516, 4416, 340, 300 }`，贴院落东南角；
- 净宽 320 = 100（男）+ 10（隔墙）+ 100（洗手池）+ 10（隔墙）+ 100（女）；
- 每侧两格坑位：48 + 6px 隔断 + 46，马桶从 6 个减到 4 个，相邻两个相距 53（仍 >40）；
- 北门洞收到 x+150..x+210，门前铺装、宫灯、logo、区域名与导览到达点一起挪；
- `interior-art.ts` 的污渍 / 地漏 / 提示牌 / 干手器 / 绿萝与洗手台台面不再写死 460×360 的偏移，
  台面高度改从房间南墙反推。

**已知代价**：`SEAT_DRAFTS` 少两个马槽，会让后续座位 id 整体前移 2；本地
`niuma:session:v1` 里存的 seatId 可能指到另一张合法座位。恢复路径只按新座位表校验，
不新增兼容层——座位快照本来就是「尽力恢复」。

### 3. 小黑屋 320×240

- `JAIL = { 4320, 4790, 320, 240 }`：**西墙、门洞 4920–4980、门前铺装 4250,4920,80,60
  与 y=4950 的支路全部不动**，只把东墙与南墙收进来；
- 北留白仍 74px，南留白从 30px 变成 110px；
- `JAIL_ANCHOR = (4470, 4980)`，三个并排反省位 ±48，押送松手点与 BFS 端点自动跟随；
- 「与影厅同尺寸」的断言改为「同北线、在东侧、体量更小」，影厅保持 460×320。

### 4. 游乐园搬到北向主路尽头

- `AMUSEMENT_PARK = { 3556, 2560, 1080, 600 }`，园区内部全部绝对坐标整体平移 **(+1336, −2960)**，
  滑道折线、器械底座、大件包围盒、灯光与气球都跟着走，不重画；
- 入口改成**南门 (4096,3160)**：正对北向主路末端（3230），门外铺装 4036,3160,120,80；
  东门 (4636,2640) 保留为侧门，北门删除，`parkFencePosts` 按边开缺口；
- Web 侧门楼 / 彩灯 / 气球改挂南门，旋转木马的硬编码灯光改为从 `PARK_RIDES` 派生；
- 南庭院保持居中，西侧树篱不再为「游乐园东门」留缺口。

### 5. 三湖只平移不改形，摸鱼亭跟着湖走

| 湖 | 平移 | 新包围盒 |
|---|---|---|
| 摸鱼湖 | (−140,−220) | 约 4900–5560 / 5000–5690 |
| 沉思浅塘 | (−150,0) | 约 4830–5340 / 2700–3120 |
| 涟漪湖 | (+380,−290) | 约 2640–3080 / 4700–5150 |

只平移是刻意的：湖形一变，每湖 6 条鱼的离岸 60 / 间距 100 采样就要重新标定。
摸鱼亭（ADR-0061）跟到摸鱼湖北岸，亭心 (5350,4800)，离水 ≥200，八根亭柱不压新东主路。

### 6. 道路、道具与植被重排

- 西主路收在 (2700,3980)，分一支到涟漪湖北岸；东主路弯向摸鱼湖北岸 (5180,4680)；
  东北支路接沉思浅塘南岸；卫生间支路压到新门洞中线 (4696,4350)；
- 删除原「西南支路 → 游乐园北门」，北向主路直接接游乐园南门；
- 湖岸长椅、路灯、野餐桌全部按新湖岸重排；花海从 8 片收到 6 片并重新手写；
- 树丛中心重写为 25 个候选（保留 ≥12 个有效簇）；孤树栅格 128 → 96、概率 0.24 → 0.3，
  把岛缩小后少掉的林荫补回来。**密度阈值不放宽**：纯草 <48%、512 窗口 <90% 继续生效。

## 后果

- 正面：
  - 广场到任一场所的步行距离明显缩短，一屏能看到游乐园、湖岸或院落中的至少两处；
  - 北门方向有了地标（游乐园），南向主路仍直通南庭院与发泄区；
  - 卫生间与小黑屋的体量与「实际使用人数」对上了，不再是大半间空房。
- 负面：
  - 布局坐标是双端共享常量，**必须同版本发布**；
  - 卫生间少两个马桶，座位 id 前移 2（见上）；
  - 三湖与亭子挪位后，旧的截图、攻略与玩家记忆里的方位会失效；
  - 押送寻路的绕行长度、散树数量这类「按旧地图标定」的测试阈值需要重新标定。
- 回滚成本：中。`world/` 三个文件与三端测试一起回退即可；
  ADR-0077 之前的布局常量完整保留在 git 历史里，不需要运行时开关。

## 复核信号

- 出现「走两步撞树 / 树长进湖」：先查 `isPlantable` 的 95px 水面留白与 55px 路径留白，
  不要直接放宽 `TREE_MIN_GAP`；
- 出现「任意 512 窗口仍然很空」：按 `layout-density.test.ts` 的采样点补树丛或花海，
  阈值是这次改动的一半目的；
- 出现「游乐园门口走不进去」：检查南门铺装与北向主路末端是否仍重叠，以及 `parkFencePosts` 的南门缺口；
- 出现「马桶或洗手台画到墙外」：检查 `RESTROOM_ZONE_W` 与 `interior-art.ts` 的台面反推是否仍从南墙计算；
- 出现「押送绕远 / 卡在门口」：先看 `escort-path.test.ts` 的门框探针，再动 `JAIL_DOOR`。

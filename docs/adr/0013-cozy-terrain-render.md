# ADR-0013：暖色 pastel 地形与 Pony Town 质感的渲染重构

- 状态：已采纳
- 日期：2026-11-02
- 关联：细化 ADR-0005（整数栅格与 nearest 采样）、ADR-0010（64 网格与地形尺度）
- 后续：边缘判定、图层拆分与底座投影见 ADR-0016（配色、遮罩平铺与贴花命中率不变）

## 背景

园区上线后，画面问题集中在四处，且都不在「单件画得好不好」这一层：

1. **地面是方块拼的**。四条土路与广场直接铺矩形 `TilingSprite`，草地与土地的交界是一条
   90° 直角，且四条路各自从自己的左上角起算平铺相位，路口撞在一起时纹理互相对不上。
2. **大面积纯色草地发空**。256px 的草地贴图在 3 倍放大后，一块色斑铺满半个屏幕，
   走三步就看出重复。
3. **遮挡只有一半**。树与角色虽然按脚底 y 进了同一个排序容器，但一棵树是**一张贴图**——
   角色走到树后时被整棵不透明树冠完全盖住，看不见人。
4. **色温割裂**。地形是深苔绿暗调（`grassBase #141D15`），界面也是冷灰绿，
   而需求要的是奶油草地 + 沙色土路的 cozy pastel。亮世界配冷界面，两边都不像成品。

另外两处是动效与阴影：角色的呼吸烘焙在图集帧里，循环里每 1.9 秒眨一次眼（比真眨眼密得多），
贴地阴影是 `0x040807 @0.55` 的炭黑色块。

## 备选方案

| 方案 | 收益 | 代价 | 不可逆性 |
|---|---|---|---|
| A. 16 张 dual-grid 拼贴块贴图 | 教科书式 autotile，任意形状都能拼 | 拼贴块内部的材质相位无法与外层 `TilingSprite` 对齐，接缝处一定露半块砖；一片土路约 200 个精灵、16 张纹理；采样栅格会把边界量化到 32px 格点，土路末端与 120px 门洞最多错位 16px | 中 |
| B. 圆角轮廓 + 遮罩平铺（采纳） | 一片区域只有 1 个平铺层 + 1 个遮罩 + 1 个草缘；边界是解析圆角而非格点近似，误差为 0；相位可显式对齐世界坐标 | 圆角半径固定为半格，不能像拼贴那样换更复杂的转角造型 | 低 |
| C. `Graphics.fill({ texture })` 图案填充 | 一条路径一次绘制 | v8 的 UV 矩阵语义跟随形状包围盒，跨区域相位难保证 | 中 |

选 B。理由是 A 的两个代价（相位接缝、格点量化）恰好是本次要解决的「硬拼感」本身：
用拼贴块去消除拼贴感，是把问题从「边界直」换成了「边界有缝」。
dual-grid 的采样思想保留在不规则形状上——林地边缘就用 32px 采样格 + 平滑噪声外推。

其余三个决策：

- **美术来源**：全部程序化生成（`Graphics` 在 `renderer.init()` 里一次烘焙）。
  接入 AI 生图 PNG 会同时破坏分层 tint 管线、seamless 接缝与 32px 整数栅格，
  且与「零外部美术」的仓库纪律冲突。
- **微动效幅度**：需求文本写「待机头部浮动 12 像素」。角色站立总高只有 48 texel，
  12 texel 是四分之一身高——那不是呼吸，是漂移。改为 1 texel，并只允许抬高。
- **树冠遮挡**：拆成树干 + 树冠两张同帧纹理，遮挡时只压树冠 alpha。

## 决策

1. **配色全量转暖**（`terrain-palette.ts`、`globals.css`、`MINIMAP_COLORS`、各处硬编码色）。
   草地 `#6F9B57`、土路 `#C2A276`、沙滩 `#D9C096`、水面 `#4F9FB0→#86CCD8`、
   树冠 `#2F5C39→#57945B`。新增 `EDGE_TINT` 表：每种材质的描边取本体色相压暗 40%
   （深苔绿 `#3D5C33`、深栗棕 `#7A5F3C`、深湖蓝 `#2F6F86`），**全站不再出现纯黑描边**。
   界面把 `--color-ink-*` 转暖褐、`--color-mist-*` 转暖白，正文对比度从 5.9:1 提到 6.2:1。
   **mint-400 `#4FE3C1` 保留为唯一冷色强调**：焦点环、选中态、主按钮全靠它，
   整体改暖会让站点变成一片橙色并失去可访问性对比。

2. **地面过渡改为「圆角轮廓 + 遮罩平铺」**。新增纯几何模块 `autotile.ts`：
   `roundedRectContour` 输出四角 1px 步进圆弧的闭合轮廓（半径 = 半格 16），
   `organicContour` 在其上叠加 5 点箱形滤波的噪声外推（幅度必须小于半径，凹角才不自交）。
   视图层用轮廓做 `Graphics` 遮罩裁切 `TilingSprite`，再沿轮廓画 2px 草缘
   （`grassTuft`，一半压进材质一半探到草地）+ 每 6px 撒一个 1px 齿（外突起 / 内凹口七三开）
   + 2px 内缘暗边。`tilePosition` 按 `rect.x % tileSize` 对齐世界相位，四条路不再各算各的。

3. **贴花层**（`decals.ts`）。64px 栅格，位置哈希（`Math.imul` 的 Wang hash 变体）
   命中率 0.12，格内抖动 ±60%，四种贴花（三叶草 / 雏菊 / 微风草尖 / 小石粒）收在一张
   64×16 图集里。水面、广场、土路、桥面不生成。独立 container 位于 ground 之上、角色之下，
   与树共用同一套视口裁剪。

4. **树拆两层**。`makeTreeTextures` 返回 `{ trunk, canopy }[]`，两张纹理共用
   72×108 画布与 `(0.5, 1)` 锚点（`generateTexture` 显式传 `frame`，否则会各自裁到内容包围盒，
   锚点必然错位）。两个精灵 `zIndex` 都为 `tree.y`：角色在树前时 zIndex 更大自然压住整棵，
   在树后时两层都在其上。

5. **树冠遮挡**。初始化时建 128px 树冠网格索引，每帧由 `GameRenderer` 把可见角色脚底坐标
   写进一块复用的 `Float32Array`，`TerrainView.occlude` 命中「角色盒 ∩ 树冠盒 且
   角色 y < 树根 y」时把树冠 alpha 压到 0.85。只处理进入/离开的差异，帧循环零分配。

6. **屏幕空间柔光层**（`ambient-light.ts`）。`Texture.WHITE` 全屏 quad +
   `blendMode = 'multiply'`，加在 `app.stage` 上、`world` 之后。按本地时刻在 8 个锚点间
   线性插值（清晨暖金 α0.15 / 白日中性 / 黄昏暖橙 α0.18 / 夜间冷蓝 α0.12），30s 采样一次。
   选 multiply 而不是 normal 叠加：normal 会抬黑位让暗部发灰，multiply 只压亮部。
   **风险**：WebGPU 下高级混合走 Pixi 的扩展路径；若某台机器上未生效，观感退化为同色
   normal 叠加（略亮一档），不阻断主流程。

7. **角色渲染器更名 `PonyRenderer`**（`character.ts` → `pony.ts`），分层顺序收敛到
   `PONY_LAYER_ORDER` 一处定义：tail → body → pattern → bodyLight → hairstyle → headwear
   → hoof → extra → eyes → eyeLight → eyewear → snout → neckwear。
   **与需求文本唯一的偏离**：鬃毛（extra）排在眼睛之前。图集里鬃毛与眼睛在同一帧的不同像素上，
   让鬃毛压过去会直接吃掉表情；读脸优先级高于「鬃毛在最上层」的字面顺序。
   同理头饰排在 extra 之前——牛角与马鬃要从帽子上方穿出。

8. **微动效抽成纯函数 `pony-motion.ts`**：`ponyMotion(pose, elapsedMs, netId)` 返回
   `{ bobTexels: 0 | -1, shadow: 0 | 1 | 2, blinking }`。
   待机周期 3.4s、行走周期 240ms（一个步幅起落两次），只抬高不下沉。
   阴影用三张预烘焙椭圆（26×8 / 22×10 / 18×12）换 `texture` 实现 squash & stretch，
   **不做浮点缩放**——`roundPixels` 只吸附顶点不吸附宽度，亚像素缩放会立刻发糊。
   阴影色从 `0x040807 @0.55` 的炭黑改为冷靛蓝 `0x191E3C`（外圈 0.16 / 内芯 0.28 两档），
   暖色地面上纯黑影子会把周围暖调吸掉。

9. **眨眼改由客户端调度**。`layout.test.ts` 规定「每一列必须被恰好一个动作覆盖」，
   所以**不能**把眨眼列从 `CLIPS.idle` 里删掉。做法：`layout.ts` 新增 `BLINK_COLUMN = 2`
   并由 `generate.ts` 写进 `sprite-layout.generated.ts`；`clip.ts` 的 `buildClipTracks`
   对 idle 做后处理剔除该列，`session.ts` 按 35s（±5s、按 netId 哈希错开）把列号临时替换为
   眨眼列 140ms。`CLIPS` 一字未动，列归属契约保持绿。行走/坐/躺/叫唤不眨眼——
   闭眼帧是站立姿势，混进别的姿势会瞬移。

10. **两个灰度开关**：`?flat=1` 退回矩形平铺（圆角与草缘全部不画），
    `?light=0` 不建柔光层。都是一行判断，用于线上快速定位观感回归。

11. **新增单测**：`autotile` / `decals` / `pony-motion` 三个纯模块各一份 `bun:test`，
    覆盖「转角无直角」「草缘只两档」「同种子逐点一致」「命中率 8%–15%」
    「bob 只取 0 或 -1」「眨眼周期 30–40s」。`apps/web` 新增 `test` 脚本接入 turbo，
    测试目录不进 `tsc`（`bun:test` 类型由 bun 自带）。

## 后果

- 正面：地面交界是圆角 + 细草，不再是方块；草地靠贴花打破平铺感；走到树后能看见自己，
  且只让树冠让路；整幅画面被同一层光笼罩，暖底冷光（mint 强调）反而更抓眼。
- 负面：
  - 一片土路从 1 个精灵变成「平铺层 + 遮罩 + 草缘 Graphics」，初始化多约 2500 个 1px 齿；
    这是一次性烘焙成本，帧循环不变。
  - 贴花约 900–1200 个精灵，全部靠 `renderable` 裁剪；视口很宽时这一层是新的批处理热点。
  - 树从 1 张纹理变 2 张，常驻显存约 +2MB（72×108×4×2×4 变体）。
  - `multiply` 在 WebGPU 上是扩展路径，属于「多数机器正常、个别机器退化为 normal」的取舍。
- 回滚成本：低。`?flat=1` / `?light=0` 覆盖地形与柔光；配色集中在 `terrain-palette.ts`
  与 `globals.css` 两处；角色动效可以用 `ponyMotion` 恒返回 `{0,1,false}` 关掉。

## 复核信号

- 出现「路口纹理错位」或「土路转角漏出草地底色」：先查 `tilePosition` 的世界相位，
  再查遮罩与平铺层是否落在同一个容器坐标系里。
- 出现「角色被树冠半透明后仍看不清」：把 0.85 降到 0.72，并检查树冠盒（`CANOPY_TOP/BOTTOM`）
  是否覆盖到了树冠真实的像素范围。
- 出现 WebGPU 机器上画面整体偏亮/偏灰：`multiply` 未生效，按上面第 6 条降级或直接 `?light=0`。
- 贴花层在 200 人同屏时出现绘制耗时上升：先降 `DECAL_CHANCE` 到 0.08（仍在需求带内），
  不要改栅格边长——64px 与 32px 采样格是整数倍关系，改了会和草缘打架。

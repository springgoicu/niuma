# ADR-0027：四足坐姿改为猫狗式——屁股落地、后腿收起、前腿直立

- 状态：已采纳
- 日期：2026-11-11
- 修订：ADR-0014 第 3 节中「`sit` 落座量 5.5 / 低头量 6」「`haunch` 按 `bodyW` 比例缩放」两条坐姿画法；ADR-0019 中「坐姿沿用坐姿基座（臀部下折、躯干不变）」的描述

## 背景

上线后的坐姿反馈浓缩成一句：**看不出坐下了**。

拆开是两处几何问题：

1. **侧视**：`sit` 只把躯干下压 5.5 texel、纵向压到 0.9，四条腿仍然按站立时的直柱从躯干底画到脚底线，
   再在肚子下方补一块 `haunch` 鼓包。观感是「四条短腿 + 肚子下一块暗补丁」，不是四足动物坐下；
2. **正视 / 背视**：`FacingOptions.sit` 同时代表 sit 与 lie，坐姿一条腿都不画，只在贴地处露两截蹄子。
   这是「趴」的语义，不是「坐」；正坐下时玩家数不出任何一条前腿。

四足动物（猫 / 狗）坐下的读法由三个信号组成，缺一个就退回「蹲」：

- **后躯折叠并落地**：后腿不再有落地腿柱，臀部形成一块贴地的大鼓包；
- **前躯立起**：肩线高于臀线，背线从肩到臀自然下斜；
- **前腿直立撑地**：前腿（几乎）保持全长，蹄子落地，与后躯形成「前面两根柱子 + 后面一个球」的剪影。

## 备选方案

| 方案 | 收益 | 代价 | 不可逆性 |
|---|---|---|---|
| A. 只调 `sit` 的落座量与头位 | 改动最小，测试零风险 | 四条腿仍是落地直柱，剪影不变，问题不解决 | 低 |
| B. 躯干用倾斜 `polygon` + 后腿折线 | 背线最自然 | 手写八点斜四边形在像素硬边下容易出锯齿；描边、圆角、斑纹遮罩都要重算 | 中 |
| C. 多块圆角矩形并集（采纳） | 复用 `roundRect` 与两阶明暗；并集 shade 只画一遍，背线靠块的圆心错位自然成坡；斑纹遮罩复用同一份形状 | 三块重叠处若逐块 `solid` 会留内部暗边，必须整体铺色 | 低 |
| D. 把腿拆成独立图层单独选帧 | 能做出真正的折叠腿分帧 | 破坏 `palette.ts` 的 slot 体系与锚点推导，图集层数、列预算全变 | 高 |

选 C。A 不解决剪影，B 的收益不及描边与斑纹重算的成本，D 与本轮「只换几何、不动列预算」的边界冲突。

## 决策

### 1. 侧视坐姿：三块并集（胸 / 腰 / 臀）

`SideOptions` 新增 `torso: TorsoMass[]`，坐姿返回三块，其余姿态返回单块。绘制与斑纹遮罩都只读这一份：

```ts
const shoulderY = FEET - a.legH * 0.94 + breathe;  // 肩线 = 前腿可见长度
const hipBottom = FEET - 3 + breathe;              // 臀块底边，屁股落地
const hipH = a.bodyH * 1.02;
const chestCY = shoulderY - a.bodyH * 0.48;

[
  { cx: BODY_CX + bodyW * 0.22, cy: chestCY, w: bodyW * 0.52, h: bodyH * 0.96, r: bodyR * 0.55 },   // 胸：窄而高
  { cx: BODY_CX,                cy: shoulderY - bodyH * 0.3, w: bodyW * 0.74, h: bodyH * 0.9, r: bodyR * 0.75 }, // 腰
  { cx: BODY_CX - bodyW * 0.24, cy: hipBottom - hipH / 2, w: bodyW * 0.62, h: hipH, r: bodyR * 0.72 }, // 臀：最靠后、最低
]
```

- **整体铺色**：先按 `(dx,dy)` 偏移把三块当一份形状铺一遍 `BodyShade`，再整体铺一遍 `Body`；
  逐块 `solid` 会在块与块的接缝留下内部暗边，把坐姿切成三块补丁；
- **后腿不画**：`sitting` 为真时跳过 `hindFar` / `hindNear`，删掉旧的 `haunch` 补丁——臀块本身就是剪影；
- **前腿直立**：`legTop` 由肩线推导（`shoulderY - 2`），两段式 `drawLeg` 照常落地，膝点保持 `±0.8` 的轻微前倾；
- **尾巴**：新增 `tailTop`，坐姿挂在臀块上缘而不是背线，长度继续受 `FEET` 约束；
- **头**：`standHeadCY + 2`。比旧坐姿的 `+6` 抬高 4 texel——头抬起来才读得出「坐着看前方」，
  但整体仍比站立低约 2 texel。

### 2. 正视 / 背视：拆分 `sit` 与 `lie`

`FacingOptions.sit` 不再包含躺姿，新增 `lie`：

- 坐姿：躯干下沉量 `+4.5`（旧 `+9`）、高度 `bodyH × 0.92`、头心 `+7`；
  在躯干两侧各画一块折叠的大腿鼓包（`legW × 1.6`，底边停在 `FEET - 6`，**不落地**），
  再在 `shoulderX` 位置画两条直立前腿；挥手侧跳过该侧落地腿，另一条继续撑地；
- 躺姿：完全保持原状（贴地两截蹄子），避免回归 ADR-0026 的床上语义；
- `legTop` 按当前姿态的躯干底推导：坐姿 `bodyCY + bodyH/2 - 1`，躺姿 `- 3`，站姿沿用站立肩点。
  继续用站立肩点会让坐姿前腿从胸口里长出来。

### 3. 座位对齐

脚底原点、`FRAME_SIZE`、`SEAT_ART.sink`（椅子 / 马桶 6、凳子 4、沙发 8、床 16）全部不动。
坐姿臀块底边从旧值约 52 降到 56（离脚底 3 texel）：角色 sprite 1:1 世界坐标，椅子坐垫覆盖
`seat.y - 11 .. seat.y - 1`，臀部落点仍在坐垫范围内，不悬空也不穿椅面。

## 后果

- 侧视坐姿：后腿消失，前腿直立可见约 15 texel，臀块贴地；
- 正视 / 背视坐姿：能数出两条直立前腿，后腿只在两侧露出不落地的大腿鼓包；
- `sitEmote` / `sitWave` 自动沿用新基座：叫唤只动嘴，挥手只抬一条前腿，另一条撑地；
- 呼吸帧仍只抬 1 texel；所有帧不越界、描边闭合（`proportions.test.ts` 全姿态遍历通过）；
- 图集列数、帧尺寸、层数、`CLIPS` 时长全部未变，客户端零改动；
- 生成物：`apps/web/public/sprites/{cow,horse}/*.png` 重新生成；`sprite-layout.generated.ts` 内容不变；
- 回滚：把 `quadruped.ts` 的 `sideOptions` 坐姿分支与 `drawFacingBody` 的 `sit` 分支退回，
  跑一次 `pnpm assets`；`sitting` / `lie` 字段保留即可（不影响旧几何）。

## 调参旋钮（从影响大到小）

| 现象 | 先调 |
|---|---|
| 屁股没落地、像悬空坐 | `sideOptions` 的 `hipBottom`（当前 `FEET - 3`） |
| 前腿太短、又退回「四条短腿」 | `shoulderY` 的 `a.legH * 0.94` 系数 |
| 背线太陡 / 太平时 | 胸 / 腰 / 臀三块的 `cy` 与 `h`，不要加帧 |
| 侧视像趴着、头抬不起来 | `headCY` 的 `standHeadCY + 2` |
| 正视图数出四条腿 | `drawFacingBody` 的 `haunchBottom`（必须 ≤ `FEET - 6`） |
| 坐在椅子上悬空 / 穿椅面 | 先核 `hipBottom`，不要先动 `SEAT_ART.sink` |

## 复核信号

- 若侧视坐姿重新出现落地后腿柱：检查 `drawSideBody` 是否又无条件调用了 `hindFar` / `hindNear`；
- 若坐姿躯干出现内部暗边：检查是否把三块拆开各自 `solid` 了；
- 若斑纹落在轮廓外：检查 `stampBlobs` 的遮罩是否仍用 `o.torso` 并集而不是单块 `roundRect`；
- 若坐姿挥手把躯干带着动：检查 `legTop` 是否误加了呼吸以外的位移；
- 若正坐在床上出现直腿：检查 `lie` 分支是否被误删或与 `sit` 合并。

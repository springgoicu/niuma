# ADR-0098：牛马公寓从「房间频道 + 室内家具」改成「窗口探头」

- 状态：已采纳
- 日期：2026-11-15
- 关联：改写 ADR-0087 第 4 条（同坐标不同频道）与 ADR-0095 的室内部分、
  停用 ADR-0082 的户型字段、沿用 ADR-0081（共享运行态口径）

## 背景

ADR-0087/0095 把公寓做成一栋楼里的六个房间频道：进屋传送到室内矩形、铺一层室内地板、
按户型档位摆家具、还能邀请朋友串门。玩法本身能跑，但代价是：

1. 客户端要维护室内覆盖层、地板四档配色、家具色块与门牌房主名；
2. 服务端要维护房间表、按设备号找回自己的房、邀请 TTL 票据、家具布局校验与同频广播；
3. 协议多出四条（邀请 / 布局 / 房间状态 / 串门通知），钱包与 HELLO 还各带一个房屋等级字节；
4. 玩家真正能感知到的只有「进屋、看地板、出门」三件事。

需求把公寓压缩成一句最直白的话：**进屋 = 从这栋楼的一个空闲窗口探出头；出门 = 回到门口继续走。**
其余复杂度一律删除。

## 决策

### 1. 窗口表成为唯一真相

`packages/shared-types/src/world/apartment.ts` 重写为「楼体 + 门 + 窗口表」：

- 每栋 4 层 × 5 列 = 20 个窗口，`APARTMENT_WINDOWS[slot][0..19]` 给出世界坐标矩形
  与探头锚点，编号从**底层**开始、自左往右；
- 窗格公式（楼层带高、横向步进、窗宽 23、窗高 22）从旧 `drawFacade` 搬到共享层，
  客户端画窗框、服务端分配窗口、客户端画头从此读同一张表；
- 楼内进不去，楼体碰撞合并成每栋一个实心矩形（24 条墙 → 6 条）。

户型、家具目录、家具网格、室内矩形、铺地四档、门牌房主名全部删除。

### 2. 服务端只记「谁在哪栋哪个窗口」

`ApartmentRuntime` 变成一张 20 格占用表 + 反向索引：

- 进屋：按玩家**脚下这扇门**取 slot（`apartmentDoorSlotAt`），取该栋第一个空窗；
  窗外全满返回 `null`，只给本人发一条「这栋楼的窗口都住满了」的系统提示；
- 出门：释放窗口，`teleport` 到该栋 `outside` 台阶，之后就是普通园区玩家；
- 断线：立刻释放并广播，不让后来的人对着空窗被拒；
- 位置仍停在门口台阶（相机不跳），头由客户端按 `slot + window` 画到窗口上；
- `Player.roomId` 保留语义：`0 = 园区`、`1..6 = 在窗口里`，用来冻结移动 / 坐躺 / 受击。

### 3. 同步：一条全量快照

新增 `S2C_APARTMENT_PEEK = 0x59`：`[op][count u8]` + count × `[playerId u16][slot u8][window u8]`。

- 全量覆盖而不是增量：上限 6 × 20 = 120 条，只在进楼 / 出楼 / 断线 / 入场各发一次；
- 只传「谁在哪扇窗」，外观仍走常规实体同步——这也是 `sim/view.ts` 去掉房间频道过滤的原因；
- 0x4d–0x50（邀请 / 布局 / 房间状态 / 串门通知）与 `APARTMENT_ACTION.Upgrade` 永久留空不复用。

### 4. 客户端：隐藏本体 + 窗口覆盖层

- `EntityView.setPeeked`：与屏外剔除分开的第二条开关，探头期间本体与昵称都不画；
- 新增 `WindowPeekView`：挂在 y 排序层**之后**（外立面深度键在楼底，头必须画在楼面之上），
  每人一个 `PonyRenderer`，朝向 `down`、待机第一帧，用窗口矩形当遮罩只留一颗头；
  占用窗口同时点亮，远处一眼能看出哪栋楼有人在家；
- 电梯厅 / 面板 / 家具 / 邀请全部退场，HUD 只剩「[F] 进入牛马公寓」与「[F] 出门」两条提示。

## 备选方案

| 方案 | 收益 | 代价 | 结论 |
|---|---|---|---|
| A. 保留房间频道，只在室内加一扇窗 | 改动最小 | 复杂度一点没减，屋里还是那套地板家具 | 否决 |
| B. 探头只做本地表现 | 零协议改动 | 别人看不到谁在家，与「窗口住人」的观感冲突 | 否决 |
| C. 服务端分配窗口 + 全量快照（采纳） | 全园区可见、稳态零流量 | 新增一条协议与一层遮罩渲染 | 采纳 |

## 后果

- 删除：`S2C_ROOM_STATE` / `S2C_ROOM_INVITE` / `C2S_APARTMENT_INVITE` / `C2S_ROOM_LAYOUT`
  的编解码、`RoomStatePacket` / `RoomInvitePacket` / `FurniturePlacement`、公寓面板组件与三个 store、
  户型升级与家具购买的扣费入口、`houseTier`（`EconomyProfile` 与 HELLO 经济段 / 钱包包各少一个字节）；
- `sim/view.ts` 不再按 `roomId` 隔离视野：探头的人必须留在 AOI 里，客户端才有外观可用；
- 免伤口径：`applyMove` 顶部拒绝 `roomId !== 0` 的移动，`C2S_ACTION` 直接丢弃，
  `sim/vent.ts` 把「窗口里的人」并入「入座免伤」挡板；
- 回归口径：`packages/shared-types/src/__tests__/apartment-layout.test.ts`（几何、整块实心、20 窗不重叠）、
  `apps/game-server/src/sim/apartment.test.ts`（空窗顺序、满窗拒客、出门与断线释放）、
  `economy-protocol.test.ts`（经济段与钱包包新长度）；
- 状态不落盘：窗口占用与本运行周期同寿命，`world-state.json` 结构不变（ADR-0081）。

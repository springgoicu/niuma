# ADR-0103：园区改为开放平面，围墙只留给必须关起来的场所

- 状态：已采纳
- 日期：2026-11-16
- 关联：修订 ADR-0097（五区室内外）、ADR-0077（卫生间 / 小黑屋 / 游乐园收紧）、ADR-0092（急救站围挡）、
  ADR-0061（国风地标）；沿用 ADR-0053（隔墙视觉从碰撞反查）、ADR-0094（场所色板与地面材质）

## 背景

ADR-0097 把园区拆成五区之后，每处场所仍按「一间房」的方式砌一圈 10px 灰墙，连不该围的地方也围：

- 企业楼被南北两排墙与走廊切成三个格子，会议室与发泄区各自带一扇门洞；
- 宿舍区、家庭影音室各是一间独立小屋，影厅东墙还留一扇 60px 门；
- 游乐园沿四边围一圈装饰矮栅栏，只留南门与东门两个缺口。

问题是这些墙已经不承担识别作用了：ADR-0094 给每处场所铺了不同地面（胡桃木 / 瓷砖 / 地毯 / 深色影厅地毯 /
橡胶垫 / 水泥），色块本身就说明「换地方了」。剩下的墙只做了三件负收益的事：

1. 把开放办公区与生活区切成一格格房间，玩家在楼里贴墙角斜走会「发黏」（ADR-0099 曾为此把走廊从 40 加到 56）；
2. 门洞位置一旦写死，导览点、门前铺装、警示条、外立面徽记都要各自反查一次墙段，改一处漏四处；
3. 视觉上全站被同一种灰带框住，五区的色温差异被墙线压平。

## 决策

### 1. 只保留「必须关起来」的六处围合

| 保留 | 理由 |
|---|---|
| 小黑屋（`JAIL`） | 禁闭玩法与保安押送都依赖「只能从西门进出」 |
| 卫生间（`RESTROOM`） | 隐私与四个坑位隔断，男女分区内隔墙必须留 |
| 医务室 / 护士急救站（`CLINIC_FENCE_SOLIDS`） | 救护车通道与西门人行门禁依赖现有围挡几何 |
| 别墅小院（`VILLA_WALL_SOLIDS`） | 院门锁是玩法的一部分（动态门栅读同一组矩形） |
| 擂台八角笼（`RING_FENCE_SOLIDS`） | 比赛边界，否则观众可以走进场地 |
| 牛马公寓（`APARTMENT_WALL_SOLIDS`） | 建筑实体，本来就不是围墙 |

其余一律改成开放平面：工作区的楼体外墙、会议室、发泄区、宿舍区、家庭影音室、企业楼走廊西端封口墙，
以及游乐园外圈那圈纯装饰矮栅栏。

### 2. 只删墙，一处在共享布局生效，两端同时可见

`CAMPUS_SOLIDS` 收敛为 `restroomSolids` + `jailSolids` + 卫生间内隔墙 + 坑位隔断 + 会议桌（桌子是家具碰撞，不是墙）。
世界几何仍是唯一事实源，因此：

- 客户端预测、服务端裁决、寻路网格、地面墙带（`props.ts` 的 `fillSolidFlat`）同时改变；
- 不可能出现「视觉拆了、碰撞还在」的空气墙；
- **坐标一个字都不改**：房间矩形、座位、桌子、导览到达点、协议字段、NPC 路径全部沿用原值。

### 3. 边界改由地面材质与既有地面色带承担

- 木地板、瓷砖、地毯、影厅深色地毯、橡胶垫、水泥地直接接到草地与铺装；
- 发泄区四沿用 `buildVentAlert` 的 4px 色带（原先贴在墙内沿，现贴到房间外沿）；
- 不新增花箱、绿篱、灯位与动效，`?venue=0` / `?light=0` 两个灰度口径的语义不变。

### 4. 同步清掉所有「场地必有墙」的渲染反查

| 位置 | 处理 |
|---|---|
| `venue-art.paintVentThreshold` + `northDoorGap` | 发泄区没有北墙就没有门口，整体删除，改由四沿色带表达 |
| `venue-art.paintCompanyCorridor` | 起点从 `corridor.x + 10` 改为 `corridor.x`（不再让开封头墙）；指向两个门洞的 `gateChevron` 与其函数一并删除 |
| `venue-art.FACADE_PROFILES` | 只留卫生间与小黑屋两条；会议室 / 发泄区 / 宿舍区 / 影音室的檐口在无南墙时本就画不出来 |
| `interior-art.roomOf` | 兜底墙厚保持 10px：无墙房间的地面装饰缩进 10px，正好成为一圈地面收边；有墙的卫生间 / 小黑屋行为不变 |
| `packages/shared-types` 门洞常量 | 删除 `MEETING_DOOR` / `VENT_DOOR` / `LOUNGE_DOOR` / `HOME_THEATER_DOOR`；`HOME_THEATER_DOOR_PAVING` 保留（铺装与导览仍用） |

### 5. 游乐园只删栅栏

`parkFencePosts()` 整体移除，`park.ts` 的 `drawFence` 与调用一并删除。
`PARK_SOUTH_GATE` / `PARK_EAST_GATE` 的 `gap` 从「围栏缺口半宽」改述为「入口铺装半宽」，
坐标不动，门前铺装与两条导览路径保持原样。

## 后果

- 碰撞矩形减少 24 个（工作区 3 / 会议室 5 / 发泄区 5 / 宿舍区 5 / 影音室 5 / 走廊封口 1），20Hz 位移裁决与寻路遍历只降不升；
- 企业楼与生活区连成一片可自由穿行的地面，玩家从楼东大门进来不再被走廊两侧的墙夹住；
- 宿舍区的北窗、壁灯、暖气片等贴墙装饰现在读作「贴地边缘陈设」，位置不动、不新增陈设；
- 测试口径改为：`campus-layout.test.ts` 钉「五个开放矩形内零 wall、卫生间与小黑屋仍有墙与门洞」，
  `theater-park-layout.test.ts` 钉「影厅东沿整条可进出」，`door-clearance.test.ts` 有门房间收敛为卫生间与小黑屋（急救站另有独立用例），
  `collision.test.ts` 钉「企业楼外墙位置现在是可走地面」；
- 小地图、区域名、导览、热区都不受影响。

## 回滚

30 天内如需恢复，只需还原两处数组：`CAMPUS_SOLIDS` 重新挂回五个 `roomWalls(...)` 与走廊西端封口墙，
`parkFencePosts()` 恢复渲染侧调用。门洞常量与被删的两个渲染方法从 Git 历史取回即可，无协议、无落盘、无数据迁移。

## 备选方案

- **只拆视觉、保留碰撞**：画面上看不到墙但仍被挡住，正是 ADR-0053 已经踩过的「空气墙」坑，直接否决。
- **保留会议室与影音室的墙做「半开放」**：这两处的墙同样只承担围合，保留会让企业楼继续被切成格子，收益不一致。
- **拆墙后补花箱 / 绿篱做边界**：与「只靠地面材质区分」的目标冲突，且每加一类陈设就要重跑留白与压角色检测。
- **把发泄区也做成开放擂台**：老板战与愤怒值逻辑虽不读墙，但相邻擂台已承担「有围栏的场地」这一角色，重复且无收益。

# ADR-0031：坐姿改为「贴地宽圆团 + 两条短前腿」，三向都必须与站立一眼可分

- 状态：已采纳
- 日期：2026-11-11
- 修订：ADR-0027（`0027-quadruped-sit-geometry.md`）第 1 节的侧视坐姿数值、第 2 节的正视 / 背视坐姿数值。
  该篇的三条读法（后躯落地 / 前躯立起 / 前腿撑地）与「三块并集」「座位 `sink` 不动」「列预算不动」的结论继续有效，
  但其中「`sit` 只下压 5.5」「`shoulderY` 用 `legH × 0.94`」「`headCY` 用 `standHeadCY + 2`」
  「正视坐姿 `+4.5 / 0.92H / head +7`」「臀部鼓包 `legW × 1.6`、底边 `FEET - 6`」这些具体数值作废。
- 关联：沿用 ADR-0014（幼态比例）、ADR-0026（床上躺姿语义）、ADR-0027 座位朝向链路

## 背景

ADR-0027 上线后的反馈仍然是一句：**看不出坐下了**，而且点名「侧坐最不明显」。

## 问题

把三向的坐姿几何量和站立帧摆在一起，问题是可量化的：

- **侧视**：`shoulderY = FEET − legH × 0.94` → 前腿可见 17.2 texel，**比站立腿长（16.2）还长**；
  胸块顶边 28.2 与站立躯干顶边 26.6 几乎同高；`headCY` 只比站立高 2。
  结果是整体剪影只矮 5 texel（47.3 → 42.3），玩家眼里就是「站着，屁股那块变成一团」。
- **正视 / 背视**：躯干下沉 4.5、压到 0.92H，腿可见 13.35，臀部鼓包 `legW × 1.6` 只向外露 3px，
  且被躯干盖住大半——坐下去的变化集中在被遮住的部分。
- **三向不一致**：侧视几乎没低，正视低了 7，同一只动物转身时观感对不上。

真正的读法是**质量分布**而不是绝对高度：站 = 高躯干 + 四条长腿；坐 = 贴地的一整块 + 两条短前腿。

## 备选方案

| 方案 | 收益 | 代价 | 不可逆性 |
|---|---|---|---|
| A. 只放大坐姿特征（臀部更贴地、背线更斜、补折叠后蹄） | 改动小，座位贴合完全不动 | 胸线与前腿长度不变，「站着多一团」的剪影不变 | 低 |
| B. 整体压低变圆：三块并集压扁加宽下移 + 前腿缩短 + 头略降（采纳） | 三向同时变矮变圆，质量落在地面附近；仍是同一套 `roundRect` 并集与两阶明暗 | 头不能跟着压太多（见决策 4），整体高度只降 5，靠质量分布而不是绝对高度取胜 | 低 |
| C. 加「坐下 / 起身」过渡帧 | 过程最清楚 | 图集列数 34→36，`CLIPS`、客户端播放窗口、所有按列索引的配件锚点全要动 | 高（跨端契约） |
| D. 给折叠后腿画一块暗补丁 / 露一截后蹄 | 多一条「后腿折起来」的叙事线索 | ADR-0027 已确认暗补丁读成「肚子下多了块污渍」；后蹄楔子会与两条前腿抢读数 | 中 |
| E. 头也一起压低（`standHeadCY + 8`） | 整体高度能再降 3 | 头沉进躯干、脖子消失，实测读成「趴着 / 海狮」，比站姿更难认 | 低 |

选 B。A 不改变剪影；C 与「客户端零改动」的边界冲突；D 是同一坑；E 试过并否掉。

## 决策

### 1. 侧视坐姿：三块并集压扁加宽，臀底与蹄底同一条线

`sideOptions` 的坐姿分支（数量全部按 `ANATOMY` 比例表达，牛马同构；括号内是牛的实际 texel）：

```ts
const hipBottom = FEET + breathe;        // 臀底：渲染后最低行 = FEET - 1，与蹄底同一条线（旧 FEET - 3）
const hipH = a.bodyH * 0.74;             // 12.0（旧 16.5）
const hipW = a.bodyW * 0.82;             // 20.3（旧 15.4）
const hipCY = hipBottom - hipH / 2;
const shoulderY = FEET - a.legH * 0.72;  // 前腿可见 13.7 / 站立 16.2（旧 0.94 → 17.2，比站立还长）
const chestH = a.bodyH * 0.72;           // 11.7
const chestCY = shoulderY - chestH / 2 + 1;
```

- 躯干仍是胸 / 腰 / 臀三块并集，**顺序固定，第三块永远是臀**：`drawSideBody` 从这里推出尾巴挂点与贴地暗面，
  不再按站立后缘（`BODY_CX − bodyW/2 − 1.5`）挂尾巴，否则臀部一变宽，尾巴就被臀块吃掉；
- 腰块 `0.72W × 0.62H` 是关键旋钮：早期版本用 `0.84W × 0.70H`，腰块一直垂到前腿的高度与宽度上，
  前腿被躯干吃掉，侧视读成「一块斜板」。收到这个尺寸后，脚底线以上能读到「前面两根柱子 + 后面一坨」；
- 头只降到 `standHeadCY + 5`（27.0）：背线比站立低 12，头只低 5。**这是刻意的**——头压到 +8 时头沉进躯干、
  脖子消失，实测读成「趴着」；坐姿要读成「坐着」，头必须还立着；
- 臀底一道 `S.BodyShade` 窄弧（`ellipseMasked` 复用躯干并集遮罩）把「整块后躯压在座位上」读出来；
  不做整块暗补丁、也不露后蹄（方案 D）。

### 2. 正视 / 背视坐姿：躯干压扁加宽，臀部鼓包向外探

`facingOptions` 的 sit 分支：

```ts
bodyCY = standBodyCY + 6.5;   // 旧 +4.5
bodyH  = a.bodyH * 0.82;      // 旧 0.92
bodyW  = a.bodyW * 1.2;       // 旧 1.14
headCY = standHeadCY + 4;     // 旧 +7；与侧视的 +5 对齐，转身时头不跳
legTop = bodyCY + bodyH / 2 - 1;   // 前腿可见 12.2（旧 13.4）
```

`drawFacingBody` 的 sit 分支：

- 臀部鼓包 `haunchW = legW × 1.9`、`haunchTop = bodyBottom − 4`、`haunchBottom = FEET − 5`，
  圆心外移到 `x0 + haunchW × 0.28` / `x1 − haunchW × 0.28`，向外探出躯干约 2px，形成梨形剪影；
  **仍然不落地**——一落地就会被数成第三、四条腿；
- 两前腿之间补一块 `S.BodyShade` 的后躯（`legW × 3.1` 宽、底边 `FEET − 3`）：不补就会留下一条
  从腿缝看穿到地面的窗口，那是站姿才有的读法。压暗是为了不抢前腿的颜色；
- 背视尾巴挂点随躯干下移（`tailTop = bodyCY + bodyH/2 − 3`），`tailEnd = FEET − 2` 不变。

### 3. 坐姿派生动作

`sitEmote` / `sitWave` 自动沿用新基座，**没有新增 `SIT_WAVE_*` 常量**：
腿变短后仍复用站姿三拍（`WAVE_REACH [4,7,1]` / `WAVE_LIFT [2,4,1]`），实测蹄子落在脸的下方、
不进胸口、不遮吻部，`overlay-frames.test.ts` 的 `< 220px`／跨度 `≤ 20` 回归线原样通过。
再加一套坐姿专用常量属于投机性抽象，需要时再补。

### 4. 不动的东西

列预算（`layout.ts` 34 列）、帧尺寸、层数、客户端播放窗口、座位 `SEAT_ART.sink`、朝向链路全部不动。

## 后果

- 侧视坐姿：整体剪影 45 高（站立 50），背线比站立低 12，前腿可见 13.7（站立 16.2），臀底与蹄底同一条线，
  脚底线那一行从「两根腿柱」变成「连成一片」的后躯；
- 正视 / 背视坐姿：剪影 45 高（站立 49），躯干压到 0.82H、加宽到 1.2W，贴地处只剩两段蹄子；
- 坐姿与站立的逐像素差异：牛 820–1257、马 672–1104（回归线定在 500，见 `sit-silhouette.test.ts`）；
- `sitEmote` / `sitWave` / 呼吸帧行为不变，仍只动嘴 / 只抬一条前腿；
- 配件锚点由 `landmarksOf` 逐列推导（manifest 里的 `cosmeticAnchors`），坐姿头位变化会自动带着帽子、眼镜走；
- 生成物：`apps/web/public/sprites/{cow,horse}/*.png` 重新生成；`sprite-layout.generated.ts` 内容不变（列预算未动）；
- 客户端零改动：坐下仍是纯贴图切换，家具 `zIndex = seat.y − 1` 永远在角色之后，不存在遮挡问题；
- 新增回归线 `sit-silhouette.test.ts`：剪影差异、躯干中线压低、侧视后躯连片、正／背视两条前腿、坐／躺头位差；
- 回滚：把 `quadruped.ts` 两处 sit 分支与 `drawFacingBody` 的 sit 分支退回，跑一次 `pnpm assets`。

## 调参旋钮（从影响大到小）

| 现象 | 先调 |
|---|---|
| 侧视像「一块斜板」，数不出前腿 | 腰块的 `w` / `h`（当前 0.72 / 0.62），再核 `shoulderY` 的 `legH` 系数 |
| 侧视像趴着、头快陷进躯干 | `headCY`（当前 `standHeadCY + 5`），不要动 `hipBottom` |
| 屁股没落地、像悬空坐 | `hipBottom`（当前 `FEET`，渲染后最低行 `FEET − 1`） |
| 正视 / 背视数出三条腿 | 后躯补块的底边（当前 `FEET − 3`）必须先收，再调臀部鼓包 `haunchBottom` |
| 正视像「一团球」、看不出两条腿 | 前躯 `legTop` 与后躯补块的宽度；不要先加头部下沉量 |
| 坐姿和躺姿糊在一起 | `headCY` 与躺姿的 `+11` 拉开，`sit-silhouette` 的头位差 ≥3 会拦住 |
| 转身时头跳一格 | 侧视与正视的 `headCY` 偏移要对齐（当前 +5 / +4，差 1 与站姿同源） |

## 复核信号

- 若侧视坐姿重新出现落地后腿柱：查 `drawSideBody` 是否又无条件调用了 `hindFar` / `hindNear`；
- 若坐姿躯干出现内部暗边：查是否把三块拆开各自 `solid` 了（必须整体 `solid` 一遍）；
- 若斑纹落到轮廓外：查 `stampBlobs` 的遮罩是否仍用 `o.torso` 并集；
- 若尾巴被臀部盖住：查尾巴挂点是否还按站立后缘 `BODY_CX − bodyW/2 − 1.5` 算；
- 若 `sit-silhouette.test.ts` 的「躯干中线压低」掉到 3 以下：说明坐姿又被调回站立高度，先看 `bodyCY` / `chestCY`；
- 若正／背视贴地行的 `S.Hoof` 变成一到三段：先查挥手分支是否误删了一侧落地腿，再查后躯补块是否盖住了蹄子；
- 若坐在椅子上悬空 / 穿椅面：先核 `hipBottom`，不要先动 `SEAT_ART.sink`。

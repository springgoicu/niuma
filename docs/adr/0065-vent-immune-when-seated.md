# ADR-0065：入座免伤——坐着的人不会被发泄创飞

- 状态：已采纳
- 日期：2026-11-13
- 关联：修订 ADR-0051 第 3 节「命中后先 `seats.stand(target)` 释放座位，再创飞落地」的结论，其余（服务端权威命中、`S2C_VENT` 9 字节事件包、1.5s 硬直）仍然有效

## 背景

园区里「办公」「睡觉」「蹲马桶」三件事在数据上完全一致：角色占着一个座位（`Player.seat !== 0`）。
发泄（`E`）原本会把坐着的人从座位上拽起来创飞，正在办公、睡觉、蹲坑的人会被反复打断。

需求是「人物在办公或者睡觉蹲马桶时不可以被踢倒」。澄清后把范围定为**所有入座状态**：
工位椅、会议椅、床位、马桶、凳子、沙发、石鼓凳、影厅椅一律免伤，不做座位种类白名单。

## 问题

- **判据只能有一个。** 座位占用由服务端 `SeatRegistry` + `Player.seat` 权威记录，客户端自报不参与；
  按座位种类列白名单会让规则随家具增加而漂移，还要在服务端与客户端各写一份映射。
- **「免伤」与「不穿透」要一起定。** 如果只是把入座者排除出候选、改打身后的人，会出现
  「我朝着前面坐着的人出招，倒的却是他背后那个」的因果错位。
- **不能靠姿态判断。** 席地而坐（`POSE.Sit` 但没有座位）与地面躺平的语义是「随便坐地上」，
  不在需求范围内，也不该顺带免疫。

## 备选方案

| 方案 | 收益 | 代价 | 结论 |
|---|---|---|---|
| A. 按座位种类白名单（`chair` / `bed` / `toilet`） | 贴近最初的三句话 | 会议椅、凳子、沙发等仍会被创飞；家具一多就要维护白名单 | 否决 |
| B. 所有入座状态豁免（`seat !== 0`） | 一条判断覆盖全部家具，无白名单漂移 | 需要接受「坐在石鼓凳上也打不动」 | 采纳 |
| C. 跳过入座者，继续打身后最近的人 | 复用现有「跳过倒地者」的写法 | 出招对象与受害者错位，旁观者看不懂 | 否决 |
| D. 命中入座者按空放结算（采纳） | 语义是「打到了但没效果」，不穿透，与直觉一致 | 出招方只听到破空音，没有额外反馈 | 采纳 |

## 决策

### 1. 入座即免伤，判据只看 `seat`

`apps/game-server/src/sim/vent.ts`：

```ts
const target = nearestInCone(world, attacker, now);
if (!target) {
  broadcastVent(world, attacker, 0, 0, 0, transport);
  continue;
}
// 入座即免伤：办公 / 睡觉 / 蹲马桶等任何坐着的人都不击退、不倒地，
// 也不穿透去打击他身后的人——这一下按空放处理。
if (target.seat !== 0) {
  broadcastVent(world, attacker, 0, 0, 0, transport);
  continue;
}
```

- `nearestInCone` 仍然只跳过处于硬直（倒地）的人；**入座者照常被选中**，由调用方判空放，
  因此坐着的人会挡住身后的人；
- 命中入座者时不击退、不落躺姿、不写 `stunUntil`、不改坐标，也不广播座位释放；
- 空放包仍是 `targetId = 0`，破空音与「退！退！退！」台词照旧由附近每个人独立播放。

### 2. 删除发泄的座位释放链路

入座者不再被命中，`seats.stand(target, RELEASED)` 与 `RELEASED` scratch 成为死代码：

- `resolveVents` 去掉 `seats: SeatRegistry` 参数，返回类型由 `SeatStateEntry[]` 改为 `void`；
- `apps/game-server/src/server.ts` 的 Tick 改为直接 `resolveVents(world, grid, transport, now)`，
  不再有 `ventSeats` 与 `broadcastSeats` 调用；
- `broadcastSeats` 仍服务入场快照、移动解算、坐 / 躺 / 起身与离场，保持不变。

### 3. 边界

- **豁免**：`seat !== 0` 的一切姿态（工位椅 / 会议椅 / 床位 / 马桶 / 凳子 / 沙发 / 石鼓凳 / 影厅椅）；
- **不豁免**：席地而坐（`POSE.Sit`、`seat === 0`）、地面躺平、行走与站立；
- **即时恢复**：起身离座会清空 `player.seat`，下一 Tick 就重新可被创飞；
- **攻击方不变**：自己坐着仍可出招，扇形、冷却、硬直与事件包格式全部沿用 ADR-0051；
- **客户端零改动**：`handleVent` 对 `targetId === 0` 直接返回，本地不会出现「别人看我坐着、我自己却躺下」的预测漂移。

## 后果

- **正面**：办公、睡觉、蹲坑时不会被反复打断；判定只有一次 `seat !== 0` 比较，无新增包、无额外分配；
  规则与家具解耦，新增座位种类不需要改发泄逻辑；
- **负面**：入座者相当于获得完全免伤，出招方打到坐着的人只有破空音，没有任何「被挡下」的反馈；
  多人贴身时坐着的人可以当掩体；
- **不变**：`S2C_VENT` 仍是 9 字节定长、`VENT_*` 常量与 `VENT_STUN_MS` 硬直模型不动，协议零变更。

## 回滚

恢复 `resolveVents` 的 `seats` 参数、`RELEASED` scratch 与 `seats.stand(target, RELEASED)` 分支，
并把 `server.ts` 的调用点改回「接收条目 → `broadcastSeats`」即可。协议与客户端从未改变，回滚不涉及数据迁移。

## 验证

- 单测 `apps/game-server/src/sim/vent.test.ts`：
  - 工位椅 / 床位 / 马桶 / 凳子上的人不被创飞：座位不释放、姿态与坐标不变、`stunUntil` 为 0，事件包 `targetId = 0`；
  - 最近的人入座时不穿透：身后站立的人同样不挨打；
  - 席地而坐（无座位）仍会被创飞；
  - 原有击退、撞墙衰减、限频、硬直与边沿用例全部保持通过；
- 手工：双开窗口，B 坐到工位上，A 贴脸按 `E` → B 保持坐姿不动，A 只有破空音；B 起身后再按 `E` → 正常击退并躺地 1.5s。

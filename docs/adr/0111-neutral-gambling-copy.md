# ADR-0111：玩家可见文案去赌化，骰子馆更名「摸鱼骰子馆」

- 状态：已采纳
- 日期：2026-11-16
- 关联：骰子馆玩法 ADR-0087 / ADR-0104；骰桌台账 ADR-0110；开放平面场所 ADR-0103；
  入座类提示 ADR-0093；版本工报口径见 `AGENTS.md`

## 背景

游乐大街的「摸鱼大赌场」在招牌、门牌、导览、小地图、HUD 区域名与到达横幅里都带「赌」字；
骰子面板、骰桌排行榜、我的战绩、结算单、八角笼观战与 1v1 挑战面板把投入叫「押注 / 下注」，
把奖池叫「彩池」，把平台服务费叫「抽水」。产品要求页面不出现赌博描述。

## 决策

### 1. 只改展示层字符串

`DICE_SIDE` / `DICE_PHASE` / `INTERACT_ACTION` 等枚举值、`DICE_TABLES` 等标识符、
`world-state.json` 骰桌账本、坐标与碰撞全部不动；只替换玩家可见文案与注释。

### 2. 统一口径

| 旧 | 新 |
|---|---|
| 摸鱼大赌场 | 摸鱼骰子馆 |
| 押一把 | 试一把 |
| 押注 / 下注 / 本局已押 | 投入 / 投选 / 本局已投入 |
| 注额 | 投入额 |
| 彩池 / 公共池 | 奖池 / 公共奖池 |
| 抽水 | 服务费 |
| 封盘 | 截止 |
| 押中 | 猜中 |
| 观战押注 | 观战投选 |
| 红池 / 蓝池 | 红方池 / 蓝方池 |
| 全押 | 全部 |
| 豹子 | 同点 |
| 街头摇骰子 | 摇骰子比大小 |
| 押大押小，别押前途 | 三颗骰子，一局摸鱼 |
| 赌桌 / 赌局 | 骰桌 / 对局 |

### 3. 指出唯一事实源

- 场所名：`districts.ts` 的 `VENUES` 与 `NAV_SOURCES` 两处；`regionAt()` 与 `NAV_TARGETS` 自动跟随。
- 两个手写点必须同步：`layout.ts` 的 `buildings` 表、`dice-hall-view.ts` 的招牌 Pixi Text。
- `arrival-copy.ts` 的副标题键必须与场所名逐字一致，否则静默回落大区句，由守护测试钉住。
- `hint-copy.ts` 的 `HINT` / `HINT_BUTTONS` / `TOUCH_HINTS` 三表以 `HINT.*` 值作键，必须一次改完。
- 骰桌台账的排行榜 / 战绩 / 结算单三个面板与 `dice-hall-format.ts` 有内联文案，无共用常量，要一起扫。

### 4. 「豹子」改「同点」，「大 / 小」保留

「豹子」是骰宝术语，等长替换为「同点」；「大 / 小」中性，不加长成「大数 / 小数」，避免换行。

### 5. 历史工报一次性清理

用户明确要求全站口径一致，故重写历史条目里的赌场 / 赌桌 / 赌局 / 押注字样，保留原意、`id`、
`date` 与排序，并追加本次记录。这是一次性例外，后续仍按「只追加、不改历史」执行。

## 备选方案

| 方案 | 结论 |
|---|---|
| 代码标识符一起改名 | 否决：触发协议与落盘迁移 |
| 只删「赌」字，保留押注 / 彩池 | 否决：合规收益有限 |
| 只改骰子馆，不动观战与 1v1 | 否决：同园区两套口径 |
| 展示层统一口径（本 ADR） | 采纳：零协议风险、可回滚 |

## 后果

- 招牌仍五字等长，牌面不变；面板文案不超原串长度。
- 新增 `copy-neutrality.test.ts`：场所名、档位、玩法名、提示三表、到达副标题与工报出现禁词即失败。
- 回滚：恢复本 ADR 的字符串、删掉守护测试即可，协议与几何无需回滚。

# ADR-0086：只展示有数据来源的内容，删除编造的身份与黄历

- 状态：已采纳
- 日期：2026-11-15
- 关联：覆盖 ADR-0052（第 7 条：部门与班次由昵称哈希派生）、ADR-0059（每日宜忌与连休预期、
  条码 / 二维码装饰）、ADR-0062（改名会换工号与部门的提示）；与 ADR-0069（只统计当日）、
  ADR-0081（落盘范围与时间口径）一致

## 背景

工牌、告示板与分享卡上有一批「看起来是真数据、其实凭空生成」的内容：

1. **伪身份**：工号 `#NM-xxxxx`、部门（六个里含「摸鱼办」）、班次都由昵称 djb2 哈希取模得到，
   工号还会随改名的提示一起告诉玩家「改名会换工号与部门」；
2. **伪凭证**：工牌照上的条码与 21×21 二维码不可扫描、金色芯片没有功能，
   `NIOMA HR · VERIFIED` 与「本卡由园区工位系统自动签发」并不存在对应系统；
3. **伪地点**：`/api/geo` 在内网、缺转发头或上游失败时返回「园区局域网 / 工位内网」与
   「赛博空间 / 边缘节点 / 未知网络」，工牌与考勤档案把编造地名当真实现实展示；
4. **伪黄历**：宜 2 项、忌 2 项与一句评语由日期哈希从 16 条与 6 句固定文案池里抽出，
   节日卡上的「连休 N 天」是写死的预期值；
5. **伪进度**：木鱼每敲一下轮播「放假进度 +1s / 离自由更近一步」，欢迎横幅写死 `shift 03`，
   公告栏常驻一条「园区重装修完成」的通知。

这些内容与真实状态并列展示，玩家无法分辨哪一条可以核对，也污染了「只统计当日、服务端为准」
的既有口径。

## 决策

### 1. 工牌只写可核对字段

删除 `employeeNumber()` / `departmentOf()` / `shiftOf()` 与 `hashName()`，
`BadgeArchive` 不再携带 `employeeNo` / `department` / `shift`。证件页保留职级称谓、
首次入职、出勤地点、园区区域、今日工时、今日如厕占比、行为统计、视野内名次、点赞与成就。
档案头部的第二行改为「今日工时」，分享卡文件名改用昵称。

### 2. 删除一切伪凭证视觉

`badge-art.ts` 与 `BadgeArt.tsx` 整文件删除；分享卡去掉条码绘制、`NIOMA HR · VERIFIED`
与随机职场金句（`WORKPLACE_QUOTES`）。印章区降级为一行文字：称号本身仍由
`getStampTitle()` 按今日工时 / 步数 / 摸鱼次数真实派生，但不再画成认证圆章。

### 3. 归属地缺失一律「未上报」

`/api/geo` 的内网、缺头、非法 IP 与上游失败分支统一返回 `{ region: '', city: '', isp: '' }`；
客户端 `EMPTY_GEO` 同样为空串，且仍写入 `sessionStorage`，保持「同一会话只请求一次」。
界面通过 `geoLabel()` 统一渲染：拿不到省市就是「未上报」。

### 4. 黄历只保留时钟真值

删除 `ALMANAC_GOOD` / `ALMANAC_BAD` / `ALMANAC_MOTTOS` / `pickTwo` / `dailyAlmanac` / `djb2`，
`HolidaySpec` 去掉 `restDays`；告示板只剩两张便签：本周下班倒计时 + 本周工时进度、
最近三个法定节日倒计时（农历仍只认 2026–2028 对照表，表外标「待更新」）。
木鱼保留真实计数与「今日 N / 20」进度，飘字收敛为「功德 +1」。

## 不在本次范围

- `park-display.ts` 的在线人数放大展示（运营口径，保留原逻辑）；
- 服务端 NPC 的随机姓名 / 状态 / 籍贯 / 合成考勤（ADR-0061 / ADR-0063，明确是 NPC）；
- F2 代码工位的假仓库彩蛋（写在身上的虚构内容，不作为数据展示）；
- 首页营销站文案与数字。

## 后果

- 工牌从「像证件套件」变成一张干净的信息卡，卡片更短、层级更清晰；
- 分享卡的条码位留白，文件名与图片内容只依赖昵称与真实统计；
- 归属地查不到时玩家看到「未上报」，不再出现两个工作在不同网络的同事显示同一句编造地名；
- 少了一处每日哈希抽取与两次取模，工牌 2Hz 推送链路上是净减法；
- 单测同步删除工号 / 部门 / 班次 / 宜忌相关断言，保留姿态、座位、点击命中、
  倒计时、周进度与节日排序用例。

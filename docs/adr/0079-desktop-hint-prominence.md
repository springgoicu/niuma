# ADR-0079：电脑端互动提示迁到画面中线偏下并放大

- 状态：已采纳
- 日期：2026-11-13
- 关联：覆盖 ADR-0068 第 3 条中「桌面提示底部居中」的落位约定；
  ADR-0059 的 64px 感应与面朝判定不变；ADR-0068 的按钮形态与点击路径不变

## 背景

电脑端靠近设施时，提示一直是底部居中的一条小胶囊（`bottom-[112px]`），
座位 / 床 / 牛马榜等可点按钮只在桌面用 `min-h-8`、11px 动作名与 10px 键帽。
玩家反馈「显示得不明显」：提示贴着底部动作条上方，又被动作条本身的高度与
聊天栏、小地图挤在同一视觉带里，在 1280×720 及更高的窗口下都需要刻意低头去找。

约束：

- 角色由相机跟随，基本处于画面正中，提示压在 50% 会挡住角色与设施本体；
- 触屏端动作盘占住右下与底部，现有的三套偏移经过实机调过，不动；
- 出现时机、按键映射、点击 → `perform` 的动作通道与服务端判定全部不变；
- 本次只调整视图层的落位与视觉分量，不改协议、不改 HUD 层级。

## 决策

### 1. 落位按设备分类，电脑端统一一个锚点

`placement()` 先判设备（`!isTouch`），再判提示类型。电脑端——包括桌面窗口被拖成
竖长条的情形——统一落在画面中线偏下：

```
left-1/2 top-[62%] -translate-x-1/2 -translate-y-1/2
```

62% 在角色脚下、又远离底部动作条，是「此刻能做什么」最容易被扫到的一档；
`-translate-y-1/2` 放在外层 wrapper 上，内层 `animate-hint-in` 的位移仍是
自己那条 180ms 曲线，两者不叠加。

告示板提示在电脑端随之上移，与其它提示同位置；触屏仍是右下角
（竖屏 `bottom-[300px] right-3`、横屏 `bottom-56 right-3`），其余触屏提示
继续底部居中（`bottom-[296px]` / `bottom-56`）。

### 2. 电脑端尺寸放大一档，触屏不动

- 按钮：`min-h-14 px-5 py-3 gap-3`，键帽 `h-8 min-w-8 text-[13px]`，
  动作名 `text-[15px]`，分隔线 `h-5`，副标 `text-[11px] text-mist-400`；
  阴影从零偏移的近距光晕换成带 y 偏移的柔和投影 `0 12px 36px -14px`，
  让按钮从场景里浮起来而不是发光装饰。
- 状态 / 劝阻胶囊：`px-5 py-2.5 text-[13px]`，加 `max-w-[min(92vw,36rem)]`
  与 `text-center`，长文案换行时仍居中；触屏保持 `text-[10px]`。
- 副标从 `mist-500`（4.5:1，刚好压 AA 线）改用 `mist-400`（6.2:1），
  放大后仍读得清。

### 3. 指针与无障碍边界不变

外层仍是 `pointer-events-none`，只有按钮 `pointer-events-auto`；
`aria-label` / `aria-keyshortcuts` / `title` / 焦点环 / `mousedown` 阻止抢焦点
全部照旧，键盘 Tab + Enter 与方向键仍归游戏。

## 备选方案

| 方案 | 收益 | 代价 | 结论 |
|---|---|---|---|
| A. 屏幕正中 50% | 最醒目 | 压住正中的角色与设施本体 | 否决（用户已排除） |
| B. 跟着设施在世界里浮动 | 指向最准 | Worker 无投影能力，需新增每帧坐标同步（ADR-0068 备选 B 同因否决） | 否决 |
| C. 中线偏下 62% + 电脑端尺寸分级（采纳） | 不挡角色、离开底部动作条、改动只在一层视图 | 电脑端告示板不再贴右下角，与 ADR-0068 记录冲突，需本 ADR 覆盖 | 采纳 |

## 后果

- `InteractionHint` 的落位函数由「先判提示类型」变成「先判设备」，
  新增提示默认落中线偏下，只有触屏的告示板保留右下角特例；
- 测试改为按设备断言：电脑端（含 `portrait`）含 `top-[62%]`、不含 `bottom-[112px]`，
  触屏横竖屏与告示板旧落位用 `isTouch=true` 断言，另补电脑端放大与触屏不变的用例；
- 回滚：把 `DESKTOP_PLACEMENT` 换回 `bottom-[112px]` 与告示板 `bottom-28 right-4`、
  尺寸三元改回原值即可；文案、映射表与动作通道不受影响。

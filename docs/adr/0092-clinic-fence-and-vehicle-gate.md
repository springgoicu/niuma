# ADR-0092：护士站围挡与救护车进站航点

- 状态：已采纳
- 日期：2026-11-15
- 关联：急救站布局与救护车沿用 ADR-0084；护士站零容忍沿用 ADR-0090；矩形岛界与地图收紧沿用
  ADR-0077；地形碰撞的子步与单轴滑行沿用 ADR-0008 / ADR-0028 / ADR-0030；围栏「碰撞与贴图同源」
  沿用 ADR-0073 的 `RING_FENCE_SOLIDS`；自动寻路网格沿用 ADR-0040；零持久化沿用 ADR-0004

## 背景

玩家反馈「护士站应该有围挡，现在可以直接穿过去」：急救站只有导医柜台与两张病床的头尾边进了
碰撞，整站四面敞开，可以从任意方向走进站内、绕到柜台背后贴着值班护士，站台与园区也没有边界感。

约束：

- 围挡不能只做视觉：挡人必须走 `WORLD_LAYOUT.solids`，服务端裁决与客户端预测共用同一份；
- 救护车照旧要开进站内交床、回自己车位，不能被自己站的围栏卡住；
- 站位、柜台、病床、落点、车位与座位 id 全部保持不变（ADR-0084 的落盘与站位契约）；
- 不为外观新增持久化或逐帧开销。

## 决策

### 1. 围挡由铺装矩形外扩 10px 派生，西侧人行门 + 南侧车辆通道

`CLINIC_FENCE_SOLIDS` 与 `CLINIC_RECT` 同源：四条 10px 厚的 `kind: 'wall'` 栏杆贴着铺装外沿
（不压地砖），厚度与擂台围栏同口径：

| 段 | 矩形 | 说明 |
|---|---|---|
| 北 | `{4990, 4250, 268, 10}` | 整段封闭，护士站位 4272 与栏杆之间留 12px |
| 东 | `{5248, 4260, 10, 210}` | 整段封闭 |
| 西上 / 西下 | `{4990, 4260, 10, 62}`、`{4990, 4378, 10, 92}` | 中间是 56px 人行门洞 |
| 南东段 | `{5170, 4470, 78, 10}` | 只封东南角，西侧敞开作救护车通道 |

- 人行门洞 y 4322–4378 与 `CLINIC_ACCESS_PAVING` 等高：铺装由 `{4660, 4328, 340, 44}` 加高到
  `{4660, 4322, 340, 56}`，门口正好接在铺装尽端；扣掉两侧 9px 玩家半径仍有 38px 净空，
  `NAV_CELL = 16` 的 A* 网格至少两列可走（与擂台 56px 门洞同口径）。
- 南面 x 4990–5170 敞开：两辆车从车位直奔东侧空地航点的直线在 y = 4470 处分别落在 x ≈ 5069 /
  5141，再加上 9px 车体半径也不碰东南段，救护车出站不会被栏。
- `kind: 'wall'`：`props.ts` 的 `fillSolidFlat` 会自动在地面层铺浅色基座带（正好是医疗白），
  客户端再叠立杆与扶手；与擂台围栏、院墙同一套口径。
- `CLINIC_SIGN` 由 y 4254 上移到 4216（脚底 4250 贴住北栏外沿），避免立牌插进栏杆；该常量只在
  急救站视图使用。

### 2. 救护车进站航点：站内伤员先到南侧通道口

出警最后一段是从 `AMBULANCE_ROAD_GATE(4096,4755)` 直奔伤员。站内北半区（柜台背后，正是打护士后
被打倒的高频点）的直线会在 y ≈ 4300 处撞西栏，单轴滑行朝北绕角，最后靠 8 秒 `UNSTUCK_MS` 贴点
瞬移进站，观感很差。

新增 `CLINIC_VEHICLE_ENTRY = { x: 5080, y: 4502 }`（通道口正南 22px、树带避让范围内）：

```ts
// Dispatched：伤员在站内时插一段「先到通道口」
if (car.leg === 2 && rectContains(CLINIC_REGION_RECT, patient.x, patient.y)) {
  this.advanceLeg(car, CLINIC_VEHICLE_ENTRY.x, CLINIC_VEHICLE_ENTRY.y, 3, now);
  return;
}
```

- 站外伤员行为完全不变；
- 通道口到柜台背后是一条不碰栏杆的直线，柜台挡路时走既有单轴滑行，亚秒级绕柜角；
- 送回方向不需要新航点：从站内去主路时 `dy > 0`，被西栏挡住后的滑行方向天然朝门洞。

### 3. 碰撞与贴图只认一份几何

`ClinicView.paintFence()` 遍历导出的 `CLINIC_FENCE_SOLIDS` 画白栏板 + 钢灰扶手 + 每 24px 一根
立杆，门口两侧再加一对带红十字的门柱；北栏与南东段按脚底 y 进深度层（站内的人画在栏杆前，
站外的人被栏杆挡住脚），东西两段落在地面层。构造期一次性生成，帧开销为 0。

## 备选方案

| 方案 | 收益 | 代价 | 结论 |
|---|---|---|---|
| A. 只围柜台后的半高工作区 | 改动最小 | 玩家仍能从站台任意位置穿进穿出，与「护士站该有围挡」的诉求不符 | 否决（用户明确选整站） |
| B. 整站四面围死 | 边界最清楚 | 救护车进不去，交床与回车位都要改玩法 | 否决 |
| C. 救护车走碰撞豁免 / 半径改 0 | 不用加航点 | 车会穿过栏杆，穿帮比绕路更难接受 | 否决 |
| D. 用 `kind: 'fixture'` 避开冬季冰棱 | 横向栏杆不长冰棱 | 与擂台围栏、院墙的口径不一致；配色几乎相同（wall vs fixture 只差 6 级浅灰） | 否决（冰棱按已知小项接受） |
| E. 本 ADR 的组合（采纳） | 边界清楚、救护车有专用通道、几何单一来源 | 多一段航点、铺装加高 12px | 采纳 |

## 后果

- 玩家只能从西门或南侧通道口进出站内，点击自动寻路同样只能走这两处；
- 站东侧的伤员由救护车单轴滑行绕过东北角，柜台背后等深处伤员先经通道口再进站；
- 冬季 `winter-art` 会给横向栏杆挂冰棱（擂台绳栏已有同样表现），属已知小项；
- 病床面中段仍然可走过：ADR-0084 需要把昏迷伤员放到床心躺着，这条缝隙不能封；
- 新增单测：门洞可通行、门洞与铺装对齐、三面挡人、两条出车直线不被拦、围挡不压铺装也不与
  柜台/病床/落点/车位重叠（`packages/shared-types/src/__tests__/clinic-layout.test.ts`），
  以及「柜台背后的伤员由救护车从南侧通道口进站接起」（`apps/game-server/src/sim/clinic.test.ts`）；
- 回滚：删掉 `WORLD_LAYOUT.solids` 里的 `...CLINIC_FENCE_SOLIDS`、`ClinicView.paintFence` /
  `paintGatePosts`、`advanceCar` 的 leg 2 分支，铺装高度与立牌坐标一并还原即可；协议、持久化与
  座位 id 都没有改动。

# ADR-0066：长椅接入座位系统，地面动物收敛为兔子

- 状态：已采纳
- 日期：2026-11-13
- 关联：沿用 ADR-0020（座位表）、ADR-0031 / 0032（坐姿与座面接触契约）、
  ADR-0042（纯客户端小动物与单图集）、ADR-0045（小鱼）

## 背景

两件事在体验上互相独立，但都落在「地图上能感知的东西」：

1. 园区有 16 张户外长椅，一直只是装饰道具：能挡人，不能坐；
2. 地面小动物有兔、猫、狗三种，用户要求只保留兔子，并让兔子更可爱、坐下时更生动。

## 决策

### 1. 长椅是一种座位，但外观仍由道具管线负责

- `SeatKind` 增加 `bench`，`seatPose` 默认落坐姿；
- 座位锚点在长椅底座前方 `BENCH_SEAT_OFFSET = 12`：长椅保留 40×16 碰撞，
  坐点必须落在碰撞盒外（玩家半径 9），12px 是「贴前沿坐下」与「不压自身碰撞」的折中；
- 长椅精灵 40×18、座面顶在帧内 y=8，因此相对坐点锚点的接触高度是 `-(18-8)-12 = -22`，
  `seatLift('bench') = 21`；
- 长椅视觉继续走 `props.ts` 的道具管线，座位渲染循环跳过 `bench`，避免出现两张长椅；
- 座位由 `PROPS` 中所有 `kind: 'bench'` 派生，追加在 `SEAT_DRAFTS` 末尾，
  既有工位 / 床 / 马桶 / 影厅座位的 id 不漂移，兼容 `niuma:session:v1`。

### 2. 地面动物只保留兔子，待机即坐姿

- 删除 `critter-spawn` 的物种权重与 `GroundSpawn.species`，任意种子下 72 只地面动物全部是兔子；
- 兔子图集仍是一张 32px 图集，帧改为 5 帧：坐姿抬头 / 坐姿抖耳眨眼 / 坐姿低头啃草 / 走 A / 走 B；
- 待机时在三种坐姿帧间轮转，行走与逃跑使用站立行走帧；
- 外形按真实兔子重绘：长耳 + 粉色耳内、圆头大眼带高光、小粉鼻与 W 嘴、圆润身体、
  绒球尾、折叠后腿与并拢前爪；
- 图集从 12×10 缩为 12×5：兔子 45 格 + 蝴蝶 6 + 小鱼 6 = 57 格，留 3 格空位；
- 蝴蝶与小鱼的数量、行为与图集位置不变。

## 后果

- 长椅按 Z 入座、移动起身；服务端 `SeatRegistry` 与协议零改动，非 bed 座位自动纳入；
- 长椅碰撞、深度排序与裁剪沿用道具管线，座位只贡献坐点与抬升；
- 兔子不再有物种维度，撒点 / 运动 / 图集代码删除三物种分支，运行期仍是标量状态、零分配；
- 回滚：长椅侧删除 `bench` 座位与相关渲染分支即可；兔子侧恢复 `COATS` / `SIDE` / `FRONT`
  三物种与 4 帧图集，并把 `CRITTER_ROWS` 调回 10。

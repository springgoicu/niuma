# 场所配色参考（venue moodboard）

本目录不存图片资产，只存「从氛围到像素色板」的对照表。

原因：园区美术是纯程序化像素绘制（`Graphics` + 构造期 `bake()`），不消费 PNG；
参考图无法直接进构建，存成图片反而会和代码里的真实色板脱节。

配色纪律与逐场所锚点色的唯一事实源在
`.codebuddy/skills/pixel-venue-polish/references/palette.md`，
代码侧对应 `apps/web/lib/game/venue-palette.ts`。改色请改这两处，不要改这里。

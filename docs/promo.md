## 三个玩乐钩子（推荐按这个顺序讲）

先让人想动手，再让人发现会被记账，最后让人有东西能带走。

1. **能创飞同事**：走到他正前方按 `E`，64px、60° 扇形命中后创飞 32 像素、强制倒地 1.5 秒，期间按方向键也起不来；700ms 冷却够连创两次，打空也有破空声。台词现成可用：「💢 发泄！」「退！退！退！」「吃我一记牛马冲撞！」「💥 判定为工伤！」
2. **工牌替你记工**：进门即打卡，时间从 `00:00:00` 一秒一秒往上走、小时不封顶。日均不到 2 小时是「实习摸鱼生」，2 到 8 小时是「标准牛马」，超过 8 小时自动升「骨灰级卷王」，并附赠一句「建议立刻前往中庭吃草」。
3. **工牌能发出去**：工号由昵称算出来，同一个名字永远同一张；部门从六个里抽，其中一个叫「摸鱼办」；档案可一键复制或下载成 480×720 的 PNG，固定工号、班次、职级、印章、条码都在上面。

补充素材：按 `F` 站到售货机 / 咖啡机 / 饮水机旁互动，每台机器三句台词轮着换（「美式，苦得像周一」）；躺床上 5 秒后开始打呼。

> 不要写：砸打印机 / 沙袋 / 情绪条 / 钓鱼 / 组队 / 私聊 / 传送 / 电梯楼层 / 游戏内随时换装——这些都还没有实现。

## 提交前的自检

趣站之家的收录门槛是「创意、功能、恶搞、小游戏」，并会删除三类留言：有订阅/定价/登录墙、换皮或有推广嫌疑、没有推荐理由。提交时注意：

1. 首行放 URL，正文先交代「是什么」，再给推荐理由，不要只丢链接。
2. 明确写出免注册、免登录、无广告、无付费墙，直接排除登录墙嫌疑。
3. 说明美术为程序化生成的原创图集，排除换皮嫌疑。
4. 推荐理由优先落在「按 E 创飞同事」「工牌走秒与职级」「工卡可下载」这三条具体动作上，比"氛围好"更有说服力；不要写未实现的玩法，也不要写死在线人数与「近期发布」这类会过期的表述。
5. 若对方追问发布时间或作者，由维护者按实际情况补充，不要编造。

# 色板与场所锚点色

## 全站色温纪律（ADR-0013）

1. 暖色低饱和 pastel 打底：奶油草地、沙色土路、浅湖绿水面；不用深苔绿暗调。
2. 任何描边 / 暗边都是「本体色相压暗」的结果，**禁止 `0x000000` 与不带色相的中性灰**。
3. 明度阶梯只留两到三档（本体 + 一档阴影，最多再加一档高光）。地面越花，角色越出不来。
4. 深色只能是有色相的深色：深苔绿 `0x3d5c33`、深栗棕 `0x7a5f3c`、深湖蓝 `0x2f6f86`、深靛 `0x2a3142`。

## 压暗算法

同一色相下按用途取不同压缩比，全部只动明度、不动色相：

| 用途 | 公式 | 例（木地板 `0xd9ab7c`） |
|---|---|---|
| 砖缝 / 细线 | 本体 × 0.85 | `0xb5835a` |
| 一档阴影面 | 本体 × 0.92 并微量降饱和 | `0xcf9d70` |
| 描边 / 深缝 | 本体 × 0.40，再向深靛 `0x2a3142` 混 10% | `0x5c4a3c` |
| 物体投影 | 固定 `0x1e2846` @ 0.18–0.22 透明度 | 冷靛，不用黑 |

超浅色（瓷砖 `0xf3f8fb`、陶瓷 `0xfdffff`）不能按 0.85 压，否则缝比砖还亮：改为「抬蓝相、降明度一档」，`0xbfd0dc` 就是这个结果。

## 现有色板索引

| 色板 | 文件 | 用途 |
|---|---|---|
| `TERRAIN_COLORS` / `EDGE_TINT` | `apps/web/lib/game/terrain-palette.ts` | 草地、土路、湖面、石砖、林地、贴花 |
| `WINTER_COLORS` | `apps/web/lib/game/terrain-palette.ts` | 冬季雪面、冰缘、冬季水色 |
| `COLOR` | `apps/web/lib/game/props.ts:35` | 室内地面族、墙体、工位、床品 |
| `COLOR` | `apps/web/lib/game/interior-art.ts:35` | 室内第二层陈设（描边/阴影/木/金属/糖果色） |

**新场所取色一律先在 `apps/web/lib/game/venue-palette.ts` 加一行**，不要在绘制函数里写十六进制。
